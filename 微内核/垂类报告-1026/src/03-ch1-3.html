1方法与分母：谁数的、哪一种「没有」

这一章不谈产品，只谈这份报告凭什么说话。正文里每一个计数都必须能指回本族的一个读数件 或一个 path:line；指不回的句子要删，不许写「大概是这样」。口径细节的唯一真值源是 方法与分母-1026.md，本章是它的排版，不是它的替代。

1.2 状态词四档：核 / 片 / 未 / 反

有据盘上 沿用上一族（口径件 §二）的册子口径，不新造词。差别只有一处硬约束： 快照级数字不许进正文，哪怕标了「待复核」。这条不是风格——上一族给「待复核」标注的快照数字仍然进了正文， 结果一个判 UNSUPPORTED、一个一手根本取不到。

档含义本轮各有多少条能不能带数字
核本轮真的打开了原文正文或表格原件 由 文档核对.py 现数（refs_status）能，且必须给可指认出处
片只拿到搜索快照 / 摘要 / 标题，正文未打开 同上不能带数字，最多写方向性语境
未链接给了但取不到，或复取后正文不含那句话 同上不能；要写明「取不到」与哪一发取不到
反与本报告主张相反的证据，或被人拿来冒充事实的话术 同上能，且只能以反面样本身份用

本轮四档全有货：「未」档里有一条是复取同一 URL 后正文不含预期句—— 它既不许被引，也不许被说成「那句话不存在」。「反」档六条全部是本件自错，逐条列在附录 D。

1.3 三种「没有」：普查 / 定向 / 未做

有据盘上 一句「没有找到」有三种完全不同的成因，混起来写就是把定向检索没够着说成市场不存在。 本件把它落成可机械检查的形状：正文里凡出现 未找到 / 没有取到 / 没有 / 0 条 / 0/ / 不存在 的句子， 所在元素必须带 data-scan 之一，缺标则 文档核对.py 判 rc=3 （口径件 §三）。这一章上面那几段就各自带着标记，读者看不见但闸看得见—— 这是本报告自己也会被自己的规矩挡住的意思。

档能说什么不能说什么
census 全量普查「在这份可枚举集合内不存在」不能外推到集合之外
targeted 定向检索「本轮这些来源里没出现」，且必须写检索面是什么 不能写成「市场没有」「没人要求」「不存在这个需求」
not_run 没做「未做 / NOT_RUN」 不能折成 0，不能用相邻材料顶，不能挂在 census 名下冒充普查

2.2 N11 与 N12 的分工：本报告的承重墙

为什么这两格要单独拎出来讲

有据盘上 已关闭方向 C6（财务 GRC 单点账本件）的重开条件写的是「出现具名的、愿意把这块从平台里拆出来单独采购的买方」， C7（规模叙事）写的是「先有被记录下来的买方预算件」。 这两条量的正是 N11——而 N11 现在是 not_run：访谈没做过，所以既不能说预算科目存在，也不能说它不存在。 N12 做过定向检索，所以只能说「本轮那五类来源里没出现」。

这条分工直接决定第 7 章能写什么：定价假设可以写（它是假设），预算科目存在与否不可以写（它是没量过的东西）。 把两格混成一个「0」，本报告就会犯上一族犯过的那一个错。

口径差异必须点名（引用底盘时不许混）

有据盘上 回执 HTML 的份数有两个不同口径：整棵树里的回执件，与桌面端 v2 自己那一个回执目录。 本件在 2026-10-26 现数是两值不同的两个数（前者远大于后者），差别来自 v2 目录只留最近几发、 而全树含历史与验收回跑。正文引用时必须说清数的是哪一个集合，具体份数以现扫为准，本件不写死 （写死会随下一份回执变谎，口径件 §七）。

真端点那一发的「核对项数」与「名义项数」不等：证据源判据是区间命名（P0–P10 这种）， 但某一发里空判与缺席不出行，所以只能说实际出行数，指 报告-验收.txt 的那三行。
