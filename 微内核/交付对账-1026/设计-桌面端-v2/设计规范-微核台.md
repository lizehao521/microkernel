# 微核台 v2 · 设计规范

本机只读的交付对账桌面端。三种本地证据摆在同一张桌上：看得见的声明、看得见的依据、看得见的缺席。  
规范里的每个数都能追到盘上读数或构建产物；不能追的写 NOT_RUN。

- 令牌：`design-tokens.json`（逐字取自 `原型-源/base.css` 与 `原型-源/v2.css`）

## 1. 定位与非目标

**一句话**：给「用 Agent 写代码的人」和「团队负责人」的一张收货台。Agent 说做完了，这里把它的 16 句声明逐条对到盘上：相符 / 不符 / 核不了；决定只在操作模式做，决定和理由写进本机记忆，并生成可离线打开的回执。

**它不做**：

- 不调度 Agent，不执行交付代码；默认不联网、不调用模型。
- 不判断代码写得好不好；只判断「声明有没有盘上证据」。
- 不改声明真假。收下不会让不符变相符；核不了不会因为收下写成通过。
- 不是防线，是取证与对账层。内核对不挡攻击；它记录「谁说了什么、凭什么」。

**可选模型组件**：

- `模型桥.py` 是独立本机进程，不是核心依赖；默认不启动，核心不需要密钥也能用全部功能。
- 只有 `WEIHETAI_MODEL_BRIDGE` 指向模型桥、且界面开关打开时，才把**问题 + 去标识证据摘要**发给桥；回答固定标 `model_says`（模型转述），**不是证据**。
- 模型不能收 / 退 / 改判定、不能写记忆、不能进回执；桥不可用或端点失败由宿主记 absent。

**两种用法**：

| 模式 | 谁用 | 做什么 | 不能做什么 |
|---|---|---|---|
| 操作 | 负责人 / 验收人 | 看队列、逐条声明、开证据抽屉、收 / 挂起 / 退回、看回执 | 不能绕过按钮允许动作；已决定不能改；不调用模型 |
| 对话 | 写代码的人 / 负责人 | 问判定、测试、执行、模型、49 格、事件、证据位置、核不了、本机记忆 | 不能收 / 退；默认本地规则 0 次调用；打开模型开关时只发问题 + 去标识摘要，答案标「模型转述」 |

两种模式共用同一份证据与记忆。切换模式不改变选中交付，也不清空对话。

## 2. 用户与首要任务

**写代码的人**：交活前想知道「我这句话能不能被盘上证据接住」。  
首要任务：问一句「测试过了吗？」就拿到「不符 + 凭什么 + 去哪看」，而不是一段解释。

**团队负责人**：一天要收多单，最怕「看起来都绿」。  
首要任务：30 秒看清哪单不能收、哪单只能挂起、为什么；做决定后有一张能转发的回执。

低门槛的落点：

- 不要求懂内核 49 格。默认先看 16 条声明的三态计数，再决定要不要点开格子。
- 每个专业词旁边都有可点的证据；点开是表，不是另一段散文。
- 空态、缺席态都写「为什么」，不写「暂无数据」。

## 3. 信息架构

```
标题栏：品牌 / 服务状态 / 模型状态 / 内核快闸 / 模式切换 / 本机目录
侧栏：工作区（交付队列、对话取证、个人记忆）
      证据源（pgagent 13 步、agentd 事件、内核 49 格）
      本机（内核快闸、回执目录、模型桥状态）
主区：
  操作：三列 = 队列 358px | 详情 | 判定动作 + 证据抽屉
  对话：聊天区 | 右栏 318px（答案四档 / 本机记忆 / 可以问）
  记忆：决定 / 对话记录 | 右栏（操作者与偏好 / 可复用理由 / 记忆文件）
证据抽屉：声明 / 步骤（或 49 格 / 事件）/ 来源；cells 与 events 抽屉加宽到 880px
模态：收下确认、清空记忆确认、内核快闸
```

### 3.1 交付队列

- 顶部四格：全部 3 / 不能收 1 / 核不了 1 / 相符 1。数字由交付单判定实时算出，不手写。
- 每张卡：单号、标题、来源副标题、6 或 5 条声明的绿红黄进度条、三态计数、处理态。
- 选中的卡有蓝色描边；已处理的卡保留，但不再可决定。
- 底部一行写清规则：「任一不符整单退回；核不了只能挂起 / 退回；全相符才可收。」

### 3.2 交付详情

- 标题下只写来源事实：单号、Agent、提交时间、范围（13 步 / 49 格 / 本机假端点）。
- 判定横幅是全屏唯一的「结论」：ACCEPTED / NOT-ACCEPTED-MISMATCH / NOT-ACCEPTED-UNVERIFIED，配一句规则解释。
- 逐条声明表：判定、声明、依据档、凭什么。行可点开证据抽屉并定位到该条。
- 底部「这份交付的边界」：不是同发、证据档混合、收下不改变真假。边界不藏在帮助页。

### 3.3 判定动作

- 三个按钮的可用性由判定决定，不由用户猜：
  - 任一 MISMATCH：只能退回（收下、挂起禁用，按钮下写原因）。
  - 有 ABSENT 且无 MISMATCH：只能退回或挂起。
  - 全部 MATCH：收下可用，退回仍可用（流程原因）。
- 退回 / 挂起必须写理由，≥ 4 字；可从四个可复用模板选，也可新增。
- 已决定再打开 → 只读，显示决定、理由、回执；服务端同时以 409 拒绝重复决定。
- 决定不会因为对话里说「帮我收下」而发生；对话会明确拒绝这类请求。模型转述同样不能触发决定。

### 3.4 证据抽屉

| 页签 | 内容 | 关键读数 |
|---|---|---|
| 声明 | 16 条声明逐条为什么、引用哪条证据 | 判定 + 依据档 + 引用 chip |
| 步骤 | pgagent 13 步逐条做什么、依据档、凭什么 | trace_sane 11 条、chain_sane、code_executed=false、网关假端点 |
| 49 格 | 294 条样例账首块 49 格 | 载荷哈希 49/49、块内链接 48/48、整账 293/293、294 = 6×49 |
| 事件 | agentd 14 条事件，按 run 分组 | 2 run、2 turn 收口、2 run 收口、2 条 resumable=true |
| 来源 | 交付证据与原始拷贝的文件、字节、sha256 | 分源提示：三份证据不是同一发 |

证据档固定五档，颜色与形状同时区分，不靠颜色单通道：实测（蓝）、转述（紫）、估算（黄、虚线）、模型自述（灰）、缺席（浅灰）。

注意两个紫色不是一件事：依据档的「转述」紫 `#6a5a9a` 说的是 claim 的依据来源；答案档的「模型转述」紫 `#5b3a9e` 说的是这条回答由模型转述，不是证据。

### 3.5 对话取证

- 四档答案，先亮档位再给正文：**有依据**（蓝）/ **核不了**（黄）/ **答不了**（灰）/ **模型转述**（紫）。
- 「有依据」必须带至少一条可点的引用；引用 chip 跳到证据抽屉对应位置。
- 「核不了」必须写缺席理由；不能写成「没查到 = 0」。
- 「答不了」只用于超出本机证据范围的问题；不调用模型猜。
- 「模型转述」只在模型桥 ready 且开关打开时出现；固定写「模型转述 · 不是证据 · 模型名 · N 次调用」，`refs` 只能是摘要里的声明编号。
- 每条回答下方固定一行来源：本地规则 · 0 次模型调用；或 模型转述 · 不是证据 · 模型名 · N 次调用。这不是装饰，是契约。
- 模型开关默认关；关时 0 次调用。打开后只发问题 + 去标识证据摘要；不发记忆、操作者、文件路径、sha256、回执、口令。
- 模型桥 off / checking / unconfigured / error 分别显示，不把检查中或失败写成 ready。
- 右栏同时给「本机记忆」（最近决定）和「可以问」（六个示例），降低开口成本。
- 对话记录只存问题、回答正文、档位、引用名与来源；模型调用按条记来源与次数。
- 输入框 placeholder 写明示例；Enter 发送，Shift+Enter 换行。

### 3.6 个人记忆

三块内容：

1. **决定**：收下 / 挂起 / 退回，理由、时间、证据 sha、回执打开 / 复制路径。
2. **对话记录**：问题、回答正文、档位、引用名、来源（本地规则 / 模型转述）与调用次数；模型输出也在本机记忆里，但不进回执。
3. **操作者与偏好**：回执署名、退回/挂起必须写理由、四个可复用理由、记忆文件路径 / 大小 / sha256 / 计数、导出 JSON、回队列。

清空记忆必须二次确认（输入 `CLEAR`），只清决定与对话，**保留**操作者名、必须写理由的偏好和四个理由模板；回执文件不跟着删。记忆写入用 `.part` + `os.replace`，避免半截文件。

### 3.7 内核快闸

标题栏绿点不是装饰：点开是 `kcheck` 的真实读数——rc、✓ / ✗ / — 三项、exe sha256、exe 字节、耗时、命令、目录、读数路径、128 行 stdout 的结尾。

- 只读自检：核隔离、账表、49 格接线；明写「不写研究账 8797 / 8799」。
- 失败态写「核不了」，不写红/绿二选一。
- 耗时是这一趟的读数，不是性能基线；每次重跑会变。
- 弹层里明写「这条快闸不核的事」：判据能不能真的红，要另跑逐针破坏，不在这条快闸里。

## 4. 证据与判定契约

### 4.1 三种证据，不是同一次执行

| 交付 | 来源 | 是什么 | 不是什么 |
|---|---|---|---|
| D-1026-01 | pgagent 真跑 `desk-1026#1` | 13 步 / 49 格 / 本机假端点；trace_sane=true、chain_sane=true、code_executed=false | 不是真模型复核；没有测试步；没有 agentd 事件账 |
| D-1026-03 | agentd 真事件 `real-agentd-1` + `agentd-27276` | 14 条事件 / 2 run / 2 turn 收口 / 2 run 收口 / 2 条 resumable=true；导出副本 | 不是丢包证明；没有投送端账本或 ACK 对照 |
| D-1026-02 | 内核样例账首块 | 294 条 = 6×49；载荷哈希 49/49；块内链接 48/48；整账 293/293；依据档 37/4/2/1/5 | 不是 pgagent 本发账；不是同一发 |

界面上三单各占一行、各自标注来源。禁止把「13 步、14 条事件、294 条账」写成同一发。

### 4.2 三态不塌

- `MATCH` 相符 / `MISMATCH` 不符 / `ABSENT` 核不了。
- 缺席必须带「为什么缺席」；能核到什么程度也写清（例：「只能核导出的 14 条自洽，丢没丢核不了」）。
- 量不到不写 0；本来没这回事不挂成未决。
- 三态计数由证据文件求和，不在前端手写。

### 4.3 判定规则

```
任一 MISMATCH            → NOT-ACCEPTED-MISMATCH（只能退回）
无 MISMATCH 且有 ABSENT  → NOT-ACCEPTED-UNVERIFIED（退回或挂起）
全部 MATCH               → ACCEPTED（可收；也可因流程原因退回）
```

- 收下只记录「我接受了这份交付」，不改变任何声明真假。
- 核不了 ≠ 通过；「没查」≠「没有问题」。
- 已决定的单不可改判；服务端 409，界面只读。

### 4.4 回执

回执由服务端生成，决策接口返回回执的字节数与 sha256：

- 回执编号、生成时间、交付单、操作者、证据范围；
- 决定与理由；
- 逐条声明（判定 / 依据档 / 凭什么）；
- 证据来源表（文件 / 字节 / sha256）；
- 边界：未执行代码、判定与回执未调用真实模型、未联网、未写研究账；
- 分源提示；
- 内核快闸读数；
- 交付证据 sha256 与**应用构建** sha256。

回执不含模型转述；判定与回执由本地规则生成，0 次模型调用。回执无外链，可离线打开；打印样式已写，但打印未实测（NOT_RUN）。

## 5. 视觉规范

- 底色是暖纸 `#f3f2ed`，卡片纯白，边界线 `#e4e2da`；主文字 `#17191e`，次级 `#4b505b`，弱文字 `#646974`。
- 强调只有一个蓝 `#1f49d6`；状态色只表达三态：绿 `#0e7a4d`、红 `#b42318`、黄 `#8a5a00`、灰蓝 `#5c6270`。
- 模型转述用紫 `#5b3a9e`，底 `#f1ecfd`，边 `#d8ccf5`；它和依据档的「转述」紫是两件事，见 §3.4。
- 侧栏深色 `#16181d`，把「工作区」与纸面内容分开；标题栏同色，保持桌面应用感。
- 圆角 4 / 8 / 12；卡片阴影只两级；不用大圆角、不用玻璃拟态。
- 字体：Segoe UI / 微软雅黑；等宽 Cascadia Mono / Consolas。数字与哈希一律等宽，便于逐位对。
- 数据表固定列宽，长 kind / 哈希 `break-all`；声明表、49 格表、事件表都不横向滚动到看不见判定。
- 动效只做位移与淡入：抽屉 220ms、模态 160ms；不闪烁、不循环动画（内核运行点除外，1.1s 脉冲）。
- 详情标题 22px，视图标题 23px，队列标题 19px；正文 13px，表格 10px，微标签 9–10.5px。字号小但对比度必须过线。

色值与尺寸见 `design-tokens.json`；表格列宽也记录在 tokens 里，改列宽要重跑截图与对比度。

## 6. 可访问性与交互

- 正文对比度 4.5:1，大字号 3:1；当前构建 13 个界面态共 2,535 个文本元素检查（逐态计数，含重复元素）0 失败；模型演示 14 态 2,634 元素 0 失败。
- 负对照在最终构建 `4db8f042` 上跑：注入 `.q-title{color:#f2f2f2}` 后 167 个检查里 3 处 1.12:1 被抓，`CONTRAST_TEETH_PASS`。
- 焦点只给键盘 `:focus-visible` 2px 蓝描边；Esc 关抽屉 / 模态；模态内按钮可 Tab 到。
- 纯装饰的分隔点 `·` 标 `aria-hidden="true"`，不参与可读文本。
- 状态不靠颜色单通道：三态同时有文字、图标、边框；依据档同时有颜色与虚线 / 底色差异；模型转述同时有「模型转述」文字与紫色。
- 抽屉 / 模态打开时设置 `aria-hidden="false"`，关闭时恢复；关闭按钮有可读标签。
- 输入框 placeholder 统一用 `--ink-3`，不用浏览器默认灰（默认灰只有 4.37:1）。
- 尚未验证：读屏器实际朗读、200% 缩放 / 320px 重排、高对比模式、减少动效偏好（均 NOT_RUN）。

## 7. 本地与安全边界

- 服务只绑定 `127.0.0.1` 随机空闲端口；拒绝 8797 / 8799 两个内核研究账端口。
- 无账号、无云端、无 CDN、无外部字体、无外链；页面 CSP 禁止外连。
- POST 只收 `application/json`、同源、≤ 64 KB；跨源 403，错误 Content-Type 400，超限 400。
- 回执文件名白名单，路径穿越 400；未知 POST 404。
- 证据与记忆不出本机；清空记忆保留偏好与理由模板。
- 不执行用户代码；pgagent 的 13 步是既有真跑读数，产品只读。
- 可选模型桥是本机独立进程，也是唯一出网点：只发问题 + 去标识摘要；不发记忆、操作者、文件路径、sha256、回执、口令；摘要上限 16,000 字符。
- 模型桥只接受带 `X-Weihetai-Bridge: 1` 的本机请求，拒绝浏览器跨源；端点地址、模型名、超时、最大 token 都从环境变量读。
- 密钥只从 `WEIHETAI_MODEL_KEY` 读，不落盘、不进日志、不回显；日志只记长度、耗时、状态与错误码。默认运行不需要密钥。

## 8. 错误、空态、缺席

- 服务没起：对话回答「本地服务没有回应」，明写这不是证据结论。
- 没有 49 格样本：抽屉显示「没有 49 格样本」，不显示空表。
- 记忆为空：对话答「记忆里还没有决定，我不编一个」；记忆页显示「还没有决定」。
- 没有对话：「还没有对话。去对话模式问一句要核的事。」
- 证据缺席：黄色「核不了」+ 缺席理由 + 能核到的边界。
- 内核快闸没跑成 / 跑着 / 没开始：三档分别写清，都不冒充绿。
- 已决定：按钮只读，显示回执；重复决定服务端 409。
- 模型未配置：开关禁用并写「模型未接入」，本地规则仍可用，0 次调用。
- 模型桥检查中：显示「正在检查模型桥」，不冒充 ready。
- 模型桥不可用 / 端点失败 / 响应不合规：回答 absent，写原因与调用次数；不重试、不猜、不写成证据结论。
- 模型回答：固定标「模型转述 · 不是证据」；不能收 / 退 / 改判定。

## 9. 文案规则

1. 说「相符 / 不符 / 核不了」，不说「通过 / 失败 / 没问题」。
2. 默认说「本地规则 · 0 次模型调用」；模型回答必须说「模型转述 · 不是证据 · N 次调用」，不暗示真模型复核。
3. 说「不是同一发」，不把三份证据混成一句。
4. 缺席必须写为什么；不写「暂无数据」。
5. 量不到不写 0；0 也要写「量到的 0」。
6. 数字不手抄；分母自印。界面里的计数来自证据文件。
7. 收下不改变真假；这句话在详情、模态、回执里都要出现。
8. 对话只读；拒绝「帮我收下」时解释边界，不训人。
9. 模型转述不是证据：不写成 measured，不当作判定依据，也不进回执。
10. 没配置模型桥时，不说「模型不可用」这种像故障的话；说「模型未接入，本地规则可用」。
