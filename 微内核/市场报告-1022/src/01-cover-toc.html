这份 v3 怎么读

先说三件会让读者本能反感的事，说完再讲别的

一、本报告不给你市场规模结论。同名类目「AI/LLM 可观测」2025 年基数有三家给法：$758M、$0.93B（仅美国）、$1.97B， 最大最小差 2.6 倍，来源全是 Tier 3 报告厂。v2 当年取的 26.9 亿美元其实是其中 2026 年的那个口径，既没标年份，也处在离散区间的上沿。 v3 把这些数字全部降级成「口径离散度」证据，SAM/SOM 一律沿用 v2 的 C 级规划假设，不升格。

二、本件的话术已经被在位者说过了。UiPath 的平台页原文写着「每一个 agent 动作、模型调用、提示、响应与批准人都记入防篡改审计轨迹」， 并直接说这就是「监管所要的证据」。它没有给出密钥管理、外部锚或离线验证机制。所以我们不能讲「没人做这件事」，只能讲 「这句话的机制层没人背书」——这是完全不同的主张，也弱得多。

三、我们的先例不是零。公开预印本 Traccia（arXiv:2607.14309，2026-07-15）已经把「执行 trace → 哈希防篡改账本 → 映射到 EU AI Act 条文」这条链做出来了。 v3 撤回所有暗示首创的表述，改把差异点收窄到四个可核对的形容词：被动的、本地优先的、出处分五档的、停止必须结算的。

三条边界，先写在前面

  • 不是合规意见。关于 EU AI Act 的全部表述只在「条文写了什么、什么时候适用」层面；哪条义务落到你身上，请找持牌法律顾问。
  • 不是尽调材料。本件没有 SOC 2 报告、没有渗透测试、没有保险。§3 会说明这为什么是采购侧的真墙，而不是可绕开的形式。
  • 效果未被证明。真人访谈 0/10、试读交接 0/1、LOI 0、付费 0；事件层（把循环过程投影给用户看的那部分）状态是 Planned，代码一行未动。

证据分级：五种状态，不许塌成一种

级含义能说什么不能说什么
A 级逐行复算／原文已读，且给出复跑命令或盘上件「本机实跑读数如此」「条文原句如此」—
B 级一手页已读，但为厂商自述或单一来源「该厂商页面这样声明」不能升格成「行业事实」
C 级作者规划假设（占比、单价、情景）「这是假设，随附假设值」不得写成调查结论
D 级二级/三级来源转述（含快照级数字）「据具名来源转述」不得写成官方原文已核
未没跑、没取到、打不开「不知道 / NOT_RUN」不得折成 0，也不得用相邻材料顶

v3 期间新加一条硬规矩：只有 A 级（读过原文正文或表格原件）的数字才允许被排版进正文。 这条是被自己的错误逼出来的——抽查前我们已把「待复核」标注加在 MT-Bench 与 LangChain 的数字上，仍然让它们进了正文，结果一个判 UNSUPPORTED、一个一手根本取不到。
