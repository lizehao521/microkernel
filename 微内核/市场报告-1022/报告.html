先说三件会让读者本能反感的事，说完再讲别的

一、本报告不给你市场规模结论。同名类目「AI/LLM 可观测」2025 年基数有三家给法：$758M、$0.93B（仅美国）、$1.97B， 最大最小差 2.6 倍，来源全是 Tier 3 报告厂。v2 当年取的 26.9 亿美元其实是其中 2026 年的那个口径，既没标年份，也处在离散区间的上沿。 v3 把这些数字全部降级成「口径离散度」证据，SAM/SOM 一律沿用 v2 的 C 级规划假设，不升格。

二、本件的话术已经被在位者说过了。UiPath 的平台页原文写着「每一个 agent 动作、模型调用、提示、响应与批准人都记入防篡改审计轨迹」， 并直接说这就是「监管所要的证据」。它没有给出密钥管理、外部锚或离线验证机制。所以我们不能讲「没人做这件事」，只能讲 「这句话的机制层没人背书」——这是完全不同的主张，也弱得多。

三、我们的先例不是零。公开预印本 Traccia（arXiv:2607.14309，2026-07-15）已经把「执行 trace → 哈希防篡改账本 → 映射到 EU AI Act 条文」这条链做出来了。 v3 撤回所有暗示首创的表述，改把差异点收窄到四个可核对的形容词：被动的、本地优先的、出处分五档的、停止必须结算的。

00 · Executive Summary

00v3 摘要：那句话说反了两次

v2 在自己身上留了一句反面：「SAM 下调可能过度悲观——如果 AI 审计在 2027 年成为独立预算科目，SAM 会回升。」 v3 用抽查过的法规时点与买方实态判这句话，结论是：方向反了两次。 在法规推动这条路上它过于乐观——高风险记录类义务被 Digital Omnibus 推到 2027-12-02（Annex III）与 2028-08-02（Annex I）， 而条文要的是「部署方保留自动生成的日志至少六个月」，不是任何机器可读格式、不是出处分档、更不是第三方件； 在采购推动这条路上它又过于悲观——真正会淘汰你的是 SOC 2 Type II 这道与法规无关的门， 而它要求的「可归属到人 + 连续留存 6–12 个月」恰好是逐调用账本天然供得上的东西。v2 把需求整个挂在「审计」这个词上，挂错了接口。

三个结论

结论一：合规不会在 2027 之前逼出这本账；不要把它写成销售理由

读到原文的两份权威件都是这么说的：NIST 官网写 AI RMF「is intended for voluntary use」A 级； EU AI Act 的 Art.12 只要求记录使用期间、参照数据库、输入数据与核验人员，条文本体不含留存时长， 「至少六个月」在 Art.26(6) A 级。 再加上执法能力这一层：截至 2026-03 仅 8 个成员国设立了市场监督单点 D 级（二级转述）。 ⇒ 任何「因为 AI Act 现在需要运行时账本」的话术都必须从对外材料里删掉，它既不准确，也是我们最容易失去信任的一句话。

结论二：预算科目没有出现，但「归属 + 连续留存」这两件门槛是真的——本件该挂在这里

唯一像样的「独立预算科目」正面证据，是 IDC 维护了一个 AI-enabled financial GRC 的 MarketScape 类目 D 级； 但类目由 IBM 这类平台占着，说明坑位在平台内，不在单点件上。 另一侧是采购实态：SOC 2 Type II 被多份材料描述为 RFP 淘汰门槛、要求 6–12 个月连续生成并留存、最常见发现项是「共享服务账号无法归属到人」 D 级，全 Tier 3。 ⇒ 判词：门槛真实，但没有任何一份被记录下来的买方要求说「逐调用记录必须可独立验证」（补证波专门找过，明写没找到）。 这是本报告最大的不确定性，v3 不把它藏进「合规趋势」。

结论三：能讲的差异收窄到四个形容词，而且要先承认先例

Traccia（arXiv:2607.14309，预印本）已把「trace → SHA-256 哈希防篡改账本 → 映射 AI Act 条文」这条链做出来 B 级； UiPath 已经把「tamper-evident audit trail for every agent action」这句话写在平台上 B 级； LiteLLM 免费网关「每个请求都带审计日志」B 级；Langfuse 的审计日志与 SCIM 锁在 $2,499/月 Enterprise 档 A 级（定价页原文）。 ⇒ 还能站住的差异只剩：被动的（不执行、不调度、不写盘）、本地优先的、出处分五档且 absent 必带理由的、停止必须结算的。 前三个已有实物与读数，第四个目前只有计划（事件层 E1–E9 状态 Planned）。

如果只记五句话

  1. 不要卖「符合 AI Act」——连条文自己都没要求这本账的形状。
  2. 要卖的是把留存与归属变成可评估对象：监管接受的是配置判断（S3 Object Lock compliance mode + Cohasset 评估，限定语「when correctly configured」），不是内容判断 A 级。
  3. 「防篡改 = 可信」这句话站不住：CT 用 Merkle 树只证内部一致，「不给两方看两棵树」是 Apple 的政策不是密码学；GoDaddy/Yeti 2025 里无效签名的 SCT 是外部研究者发现的，不是树发现的 A 级。
  4. 可信权威托管账这个形态被 AWS 自己撤了：QLDB 支持止于 2025-07-31，迁移目标 Aurora 明确「不维护永久不可变记录，历史要作为审计数据存到库外」A 级（文档横幅原文）。
  5. 本件唯一被证明的东西是「机械正确 + 尺子会红」：四道闸实跑、KPI=4 与反臂 0、六态退出码、49 格逐发落账。协同体验更好从未被证明（真人 0/1）。

02 · Regulation

02法规时线重算：账本义务现在到底要不要

2.1 Art.12 与 Art.26(6) 的分工

读到原文的 Art.12 只要求：高风险系统在整个生命周期内技术上支持自动生成日志，记录范围包括使用期间、参照数据库、输入数据（造成匹配的那些）与核验人员，并指向 Art.26。 条文本体没有任何留存时长，也没有任何格式规定。 「至少六个月」出现在 Art.26(6)：部署方须保留系统自动生成的日志，期限按预期目的定，且「至少六个月」，除非适用的联盟或成员国法律另有规定。

条文要的对象
部署方保留系统自己生成的日志
条文没要的
格式、字段、分档出处、第三方件、可独立验证

⇒ 直接后果：本件的「49 格 + 五档出处」不是法定要求，它是内部复核装置——回答「谁的哪一次调用被账本改写了结果」。把后者讲清楚，比把前者说成合规要可信得多。

2.3 自愿框架为什么撑不起预算

NIST 官网原话是 AI RMF「is intended for voluntary use」，生成式 AI Profile（AI 600-1，2024-07-26）同族自愿； 两者提供的是风险类与建议动作清单，不规定任何特定留存件。ISACA 的实操描述更关键：因为 42001 与 27001 同族， 团队的真实做法是把 AI 控制项「折进既有审计节奏与证据里」——也就是说，审计师接受复用既有管线。

中介话术样本：有人在替监管立法

一家 ISO 42001 代办机构的页面声称现场审核会问「是否保存至少 12 个月的输入输出日志供追溯」，并归给「Clause 8.2.3 及附件 B 的强制性要求」。 本轮在任何 A/B 级来源里都找不到这条要求。它的价值不是「证明 ISO 有这个要求」，恰恰相反—— 它证明市场上存在把自愿框架包装成强制要求的推销话术，而这正是学界提醒要打折的那类来源（卖合规服务者自称无偏见，实则既有既得利益）。 ⇒ 对我们的含义：我们的客户会被这种话术教育过一遍，我们的诚实表述反而听像「卖得不够狠」。这是真实的销售摩擦，不是修辞。

智能体专项法律分析的位置也要更正：我们曾把 Nannini et al.《AI Agents Under EU Law》（arXiv:2604.04604，2026-04-06）称作「唯一一份」， 它自述为该方向第一份系统性监管映射（预印本），涉及 Standardisation Request M/613 下的草案协调标准、九类 agent 部署分类， 四项挑战为网络安全、人类监督、多方行动链上的透明度、运行期行为漂移。最后一项与本件同题——但它是预印本，不是监管意见，不能当依据卖。

03 · Buyer Gates

03买方门槛三件套：归属 / 连续留存 / 可分发报告

3.1 门槛真实存在，但与法规无关

门槛买方实际要的东西本件能不能供上来源强度

3.2 没人要求「逐调用记录可独立验证」

这是一条自我否证的检索结果

补证波专门去找「客户/监管明确要求 agent 逐调用记录须可独立验证」的一手件， 结论是：没有取到，并且该路子代理在报告里明写「nearest thing is an unsourced practitioner assertion」。 我们把这个空洞放进正文而不是放进附录，因为它是本报告最重要的负结果： 如果连「要求」本身都没有被记录下来，那 v2 那句「等它成为独立预算科目」就不是乐观不乐观的问题，而是尚不存在。

但同一批检索给出了两个不依赖法规的正面信号：

  • 买方把合规排在第一位
    云 AI 规模化障碍榜：治理/安全/合规 53% > 数据质量 40% > 成本 30% D 级
  • 治理成熟度是缺口
    约 1/5 公司对自治智能体有成熟治理模型，74% 计划部署 D 级（厂商引 Deloitte）

⇒ v3 的接口建议：不卖「合规要求」，卖「买方自己承认排在第一的那件事」——他们要在没有时间线压力的窗口里，把 agent 行为变成可归属、可持续留存、可分发的复核对象。这句话比「Art.12 要求你」小，但站得住。

资本侧对照：这个细分的拉力很小

最接近本件定位的纯玩法子 AgentOps.ai 只募到 $2.6M 预种子（新闻稿，无 Series A、无 ARR 披露）； 相邻观测件 Observe 是 $145M B 轮、Dash0 报 $110M B 轮估值 $1B；被点名为「agent 审计/标准/保险」方向的 AIUC 报 $40M A 轮（累计 $55M）—— 但该条只到聚合号，未一手核实，v3 不据此下结论。 读法：资本愿意为「控制平面 + 服务」出钱，不太愿意为「被动的单件」出钱。这与 v2 的功能市场判断一致。

熊案三条（v3 复核后仍然成立）

① 记录已免费。LiteLLM、Langfuse 自托管、Arize Phoenix 单容器都能记；OTel GenAI 语义约定已被云厂商与主流编码 agent 采纳， 买家开箱就有标准格式遥测。
② 没有 SOC 2 就进不了门。本件作者侧没有任何审计件，且这一门槛与法规无关、无法用产品能力绕过。
③ 合规件是没人读的勾选框。支撑证据有两类：本件自己的双臂实验量不出增益； 以及一项针对 LLM 追踪平台的公开审计——Arize Phoenix 鉴权开关默认关闭，一支无凭据的团队对着暴露端口取回整套后端， 含系统提示词与 9 个仍有效的第三方凭据。如果连「记录」本身都不被保护，「更多记录」就不是买方在意的质量。

07 · Route & Gates

07推荐路线与五道闸：改判据不改骨架

v2 的五道闸结构保留——它的价值在于「每道闸都能红」。v3 只做两件事： 把判据换成盘上可数的东西，并把一条从未真跑过的闸（G1.5）标回它真实的状态。

7.1 路线

  1. 先把过程投影做出来（事件层 E1–E9）：今天轨迹页是跑完才写，「实时可见」这句还说不出口。这一步是本件唯一能把 L5 从 Planned 推到 Wired 的动作。
  2. 再补完整性机制（L2）：外部锚或非写方验证器。CT 的教训写死了一件事——运营日志的人不能同时是唯一验的人。
  3. 并行做出版（D 路）：把「出处五档 + absent 必带理由 + 停=结算」写成可被引用的件，而不是产品页文案。先例已在（Traccia），我们不占首创，只占清晰度。
  4. 销售动作放到 G2 之后：在拿到 SOC 2 之前，任何采购动作都会在同一面墙上重演。

8.2 单位经济：三件不能说的

  • 不能说获客成本与转化。补证波明写 OSS free→paid 转化率、企业安全评审时长、试点周期「一个可信数字都没取到」，且两次检索因查询校验失败耗尽预算 ⇒ §12（研究件）与附录 D 里这块是空白，v3 不用任何代理值顶替。
  • 不能说 LTV/回本周期。依赖上一条。
  • 不能说「私有化省合规成本」。Cohasset 那条限定语「when correctly configured」意味着责任在配置方，省不掉审计。

12 · Verdict

12结论：那句 SAM 的判定

v2 留下的说法v3 判定依据
「SAM 下调可能过度悲观；若 AI 审计成为独立预算科目，SAM 会回升」 不成立（现有证据不支持回升）；但下调的理由也挂错了 回升所需的三个前提都没被记录到：① 记录类义务被推到 2027-12/2028-08；② 找不到任何「逐调用记录须可独立验证」的买方要求（补证波明写未取到）；③ 唯一像样的类目信号（IDC 金融 GRC）由平台占位。
挂错之处：真正活跃的门槛是 SOC 2 型「归属 + 连续留存」，与法规无关，且本件能供上其中两件（另两件不能）。
「这是功能市场，不是平台市场」成立，且比 v2 更硬记录层商品化 + 声明层被占用 + 机制层无人背书 + 细分资本拉力小（$2.6M vs $110M+）
「可防守差异不是哈希链或 49 格，而是证据包规范、拒收计数、版本三元组、R/N 协议」成立CT 族材料把「哈希只证内部一致」钉死；QLDB 之死是产业级反证；Traccia 已占「哈希 + 条文映射」的学术位置
定价四档团队版下调，证据包版无 G3 不得报价竞品档位与留存分级定价锚点（A/B 级）
「研究出版 + 开源先行」成立，D 路优先度上调先例已在 ⇒ 用出版确立位置比用营销便宜且可信

12.1 一段不能跳过的话

本报告最有用的部分不是「能不能卖」，是三条否定： 别卖合规（连条文都不要求这个形状）、别卖防篡改（机制我们还没做）、别卖「用了更准」（我们自己的双臂量不出增益）。 剩下的可卖之物很小但可核对：口径可核、停止可交账、每发的依据指得回哪一格。 如果这三件在 2027 年之前没有买家愿意书面承认需要，本件的正确终局是 D 路的公共件，而不是 B 路的商品。
