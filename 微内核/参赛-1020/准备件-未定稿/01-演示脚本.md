# 3 分钟演示脚本（准备件，未定稿）

- 适用：Windows 10/11 x64；PowerShell 5.1+；不需要联网、不需要管理员权限。
- 演示物：`构建-1017/agentkernel-2026-10-19-win-x64.zip`（26,774,478 B，33 个文件）+ 本目录的 `02-环境与安装/demo-ledger.jsonl`（100 条，49,048 B）。
- 实测：`02-环境与安装/demo.ps1` 一条命令跑完四段，退出码 0；读数见 `证据/demo-ps1-run.txt`。
- 说明：这是**演示脚本**，不是最终提交包；C1/C2/C3 未确认前不建 5 目录包、不报名。

> 一句话开场（15 秒）：
> “AI 改了模型输入或输出，事后怎么复核？Agentkernel 把每一次调用的元数据逐格写进一条哈希链；事后不用信任我，拿账本自己重算。”

> 先划边界（必须说）：
> “它不是防火墙：不拦请求、不改模型输入、不产训练数据；它只做记账与复核。今天演示的是‘账本能不能被第三方复核’，不是‘拦住了多少攻击’。”

## 分镜与口播（总 3:00）

### 0:00–0:20 问题

画面：黑底白字三行——

```
AI 说“我改了”
审计说“拿证据”
可证据在哪里？
```

口播：

> “模型调用每天都在改输入、改输出。出了事，平台说‘日志有’，但日志在谁的库里、有没有被改过，第三方核不了。我们把这个缺口做成一个可执行件：**每次调用的元数据逐格落账，账本是一条哈希链，任何人拿字节就能重算**。”

### 0:20–0:50 开箱：先证明包没被动过

画面：PowerShell 窗口，输入——

```powershell
.\install.ps1 -ZipPath "C:\path\agentkernel-2026-10-19-win-x64.zip" -Target "$env:TEMP\ak-demo"
```

预期读数（实测，`证据/install-ps1-run.txt`）：

```
zip sha256 = 236517a21d50ab9d3969c46354e477a881e2a1c58a4362245a104b15540abeab
[OK]   zip hash matches
[OK]   extracted to ...\ak-demo
manifest entries checked: 32; OK 32 / mismatch 0 / missing 0 / unparsed 0
[OK]   MANIFEST.sha256 verified (32/32)
```

口播：

> “先核包。zip 哈希对上一个固定值；解压后清单 32 条逐条重算，32 条全对。清单自身不在清单里，所以分母是 32，不是 33。”

### 0:50–1:25 快闸：判据自己会印，也会说“核不了”

画面：继续同一窗口——

```powershell
cd "$env:TEMP\ak-demo\agentkernel"
.\bin\kcheck.exe
```

预期读数（实测，`证据/kcheck-output.txt`）：

```
== 1. 与 Agent 框架的隔离 ...
✓ 只依赖标准库；泄漏 0 处、测试文件里泄漏 0 处、cgo 0 处、认不出 0 处
— 依赖闭包核不了：PATH 上找不到 go，也没给 GOBIN_EXE（这一路核不了，不是合格）
...
✓ 全部通过（项数由上面自己数，不抄在这里）
kcheck exit code = 0
```

口播（**不要跳过这一句**）：

> “它最后一行说‘全部通过’，但上面有一行是‘**核不了**’：这台机器 PATH 上没有 go，依赖闭包这一路没核。**‘全部通过’不等于‘所有项都核过’**。快闸自己印了 40 行 ✓（含末行汇总）、7 行 —；7 行 — 里 3 行是非判定项（依赖闭包 1 条、读者声明 2 条），另外 4 行是口径说明。这一条我们不在演示里藏。”

### 1:25–2:20 账本：链自洽、每格谁算的、某一发记了什么

画面：新开一个 PowerShell 窗口（服务窗口）——

```powershell
$env:KAUDIT_TOKEN = [guid]::NewGuid().ToString("N")
.\bin\kaudit.exe -journal "C:\path\demo-ledger.jsonl" -listen 127.0.0.1:8788
```

预期启动行（实测，`证据/kaudit-serve-8789.txt` 是同一份账本在 8789 的启动行）：

```
kaudit 只读服务：127.0.0.1:8788（账本 ...\demo-ledger.jsonl，100 条，链：green）
```

画面：回到第一个窗口——

```powershell
curl.exe -s -H "Authorization: Bearer $env:KAUDIT_TOKEN" http://127.0.0.1:8788/v1/verify
```

预期（实测，`证据/verify-100.json`）：

```json
{"checked":100,"entries":100,"no_preimage":[],"state":"green","text":"✓ 链自洽（共 100 条，其中 100 条比对过原像）"}
```

口播：

> “第一问：链自洽吗？100 条，100 条都比对过原像。‘比对过原像’是关键：链自洽只说明顺序没断，比对原像才说明每一格的字节真的能重算出来。”

画面：

```powershell
curl.exe -s -H "Authorization: Bearer $env:KAUDIT_TOKEN" "http://127.0.0.1:8788/v1/read_back?session=mount-check&call=1&side=input"
```

预期（实测，`证据/readback-20cell.json`）：

```
20 格 = 18 格 measured + 2 格 estimated；absent = 0
例如 tokens = ≈42（这是估算，不是测量）：估的是挂载验收用的合成演示值，不是真实测量
```

口播：

> “第二问：每一格是谁算的？20 格里 18 格是 measured，2 格是 estimated，估算的格自己带‘这是估算，不是测量’和来源。**不把估算写成测量**，这是这个件最重要的规矩。”

画面：

```powershell
curl.exe -s -i -X POST -H "Authorization: Bearer $env:KAUDIT_TOKEN" http://127.0.0.1:8788/v1/read_back
```

预期（实测，`证据/post-405.headers`）：

```
HTTP/1.1 405 Method Not Allowed
{"error":"这个服务只读：没有任何写入口（record/check 请走本机 stdio 外壳 kernel.record_call）"}
```

口播：

> “第三问：能不能改账？不能。非 GET 一律 405，**而且与口令无关**：写路径根本没有。只读与鉴权各管各的。”

### 2:20–2:45 能红一次：篡改第 50 条，服务拒绝载入

画面：停掉服务后，在 PowerShell 里篡改一份副本的第 50 条 `claim`，再启动——

```powershell
$bad = "$env:TEMP\demo-ledger-tampered.jsonl"
Copy-Item .\demo-ledger.jsonl $bad
$lines = [System.IO.File]::ReadAllLines($bad, [System.Text.Encoding]::UTF8)
$lines[49] = $lines[49] -replace '"claim":"[^"]*"', '"claim":"tampered"'
[System.IO.File]::WriteAllLines($bad, $lines, (New-Object System.Text.UTF8Encoding($false)))
.\bin\kaudit.exe -journal $bad -listen 127.0.0.1:8790
```

预期（实测，`证据/kaudit-tampered-refused.txt`）：

```
kaudit: 这份账本不肯被载入（链不符或字节不对）：kernel: 读回来的账本链不符，拒绝载入：第 50 条整格指纹重算不符（某格被改）want=... got=...
```

退出码 1，端口没有起来。

口播：

> “现在把第 50 条改一个字，不碰哈希。服务不是‘读出一个绿色’，而是**拒绝载入**、退出码 1、点名第 50 条。**它宁可不开门，也不给一个错答案**。这就是‘能红一次’：判据不是只会绿。”

## 附录 C：常见失败

| 现象 | 原因 | 处理 |
|---|---|---|
| `目标目录非空，拒绝覆盖` | `install.ps1` 不覆盖已有目录 | 换一个 `-Target`，或自己清空后重跑 |
| `zip 哈希不符` | zip 被改过或拿错版本 | 不要继续；重新取发布件 |
| kcheck 里有“核不了” | PATH 上没有 go，依赖闭包这一路核不了 | **这是三态里的“核不了”，不是绿**；要补就设 `GOBIN_EXE` 后重跑 |
| 8788 被占用 | 已有服务在跑 | `demo.ps1 -Port 8791` |
| PowerShell 拒绝执行脚本 | 执行策略 | 用 `-ExecutionPolicy Bypass`（不改成永久策略） |
| 中文乱码 | 控制台代码页不是 UTF-8 | 先 `chcp 65001`；脚本本身已设 `OutputEncoding` |

## 附录 D：演示不证明什么（必须与口播一致）
