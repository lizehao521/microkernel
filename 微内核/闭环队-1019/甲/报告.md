账本是**稠密**的：每一发都写满 49 行，没有「整行缺失」。所以「缺席」不是「没有这一行」，而是该行 payload 里 `Absent:true`（basis=5）。「为空」是 payload 为空串 `""` / 空数组 `[]` / claim 写着「（这一格是空的）」。

判定三态（verify_cells.js 的判据，逐格逐发跑）：
- **absent（缺席）**：payload 解出对象且 `Absent===true`（basis=5，claim 以「—（没量到，不是 0）」开头）。
- **empty（为空）**：claim == 「（这一格是空的）」，或 payload ∈ {`""`, `null`, `[]`}。
- **filled（填过）**：以上都不是（含裸整数 0、false、非空串、非空数组、`Absent:false` 的 Measure）。
- **NEVER-FILLED** ＝ 该格在 70 发里 filled 计数 == 0（即每一发都 absent 或 empty）。

> 口径纪律：裸整数 `0`（如 tool_calls=0、content_bytes=0、clamp_rounds=0）算 **filled**（量到 0 是一个值），不算「为空」；只有空串/空数组/「（这一格是空的）」标记才算 empty。这条把「量到 0」和「没量到 / 空」分开，避免把 0 当缺席。
