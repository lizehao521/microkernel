# AgentHub 1021（`Desktop\微内核\AgentHub-1021\`）

**是什么**：与 pgagent（编程Agent-1020，贴代码九步收口件）**并列的另一台**——通用自然语言对话 Agent 应用：
工具注册表 + 自主选件真跑 + 上下文记忆 + 重试/降级 + SSE 过程可视化。全仓 `grep` 确认过没有现成 registry 可复用，
所以新起模块而不是改 pgagent（避免把两台的身份混进同一本账）。

**Why**：2026-10-21 长期目标（Better Harness 那条 objective）要的是"系统级 Web 应用 + 可扩新工具"，
pgagent 的固定九步与内核 48 键契约不覆盖这个形状。
**How to apply**：谈"Agent 应用/工具注册/记忆/重试降级"时用这台；谈"代码分析收口件/内核记账"时用 pgagent。

## 结构（`src/hubd/`，package main，只听 127.0.0.1）

## 这台机器教我的两条（可迁移）

1. **"门口挡"必须在调起之前**：白名单写在工具内部判，账上就分不开"没打出去"与"打了失败"（`attempts` 会被记成 1）。
