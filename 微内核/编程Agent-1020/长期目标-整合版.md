**贴代码 + 提问 → 看 Agent 一步步把它拆开、量出能数的、说明数不出来的 → 交一份带出处的结构化结论；
全程每一发落进内核账，KPI「账本触发过几次决定」≥1 且反臂能红。**

## 三块边界（并条之后不动的三条）

1. **内核包与 `contract.md` 的 48 键 / 49 格一个字不动**（v1 冻结）。宿主只消费格。
2. **默认不执行用户代码**。分析只读字节 + 解析 AST；要跑必须显式开关、本机临时目录、带超时。
3. **出处五档不塌**：`measured / estimated / model_says / relayed / absent`；`absent` 带理由，
   "没量到"绝不写成 0；无凭据的那一路一律 **NOT_RUN**。真流量未批准不打 8797/8799。
