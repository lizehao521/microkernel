## 3. 这一段抓到的两个真问题（不是打磨出来的，是针逼出来的）

1. **加总恒等式原本是假的。** 第一版 `mixOf` 把条数直接 = `len(findings)+len(unknowns)`，
   非法档名（比如 `basis="我觉得是"`）会被 `add` 静默丢掉、MixOK 照样报「对得上」。
   针 1（`TestMixIdentityCatchesCollapsedBucket`）第一次跑就 FAIL 逼出来：现在非法档名不进任何桶、
   只进 Total，于是 `加总 ≠ 条数` ⇒ MixOK=false，并把塌档的名字打印出来。
   **这就是「全绿先证尺子会红」** —— 针 9 再往上套一层：判分器 `reporter` 对假断言必须 `Fails+1`，
   否则 selfcheck 的 `[OK ]` 是白给的。
2. **`LHS` / `MustSub` 这类编译错**是 `go vet` 抓的，不是我看出来的；AST 字段真名是 `Lhs`/`Rhs`。

# W7 多语言保守降档一整份（10-21 00:25 → 00:35，时刻取自 getmtime）

## 这段做了什么

新增 `langs.go`：语言嗅探 + Python 七族 + JavaScript 七族 + 通用两族的**文本级**判据。
Go 那一侧仍走 AST（`goRules`），其余语言**不引第三方解析器** ⇒ 命中一律 estimated。

| 语言 | 判据族 |
| --- | --- |
| Python | `bare-except` `except-pass` `mutable-default-arg` `none-compare` `long-def`(按缩进量跨度) `print-as-log` `unused-import(maybe)` |
| JavaScript/TS | `loose-equality` `empty-catch` `eval-or-new-function` `debugger-left` `console-log` `var-left` `unused-import(maybe)` |
| 通用（任何语言） | `todo-left` `hardcoded-secret(maybe)` |

每条都自带"为什么这种形状通常糟" + "改法与风险" + "怎么复验"，且复验那句一律指向**该语言自己的工具**
（ruff / eslint / pyflakes / go vet），本件不代跑、也不替它们下结论。

**语言判定本身也记账**：`lang_how` 分"用户显式选定"与"嗅探推断（不是解析出来的）"，
`lang_why` 印出命中了哪些正则、得分多少。第 ② 步那句话里明写"函数/import 两个数是文本匹配数出来的"。

## 两条被浏览器实测揪出来的缺陷（都已修，且各配一根会红的针）

1. **`==` 的正则把最常态写法漏了**：我第一版写成"前面不许是空格"的字符类，于是 `row.id == 3` 扫不出来，
   JS 考卷只命中 5 族。Go 的 regexp 是 RE2、**没有前后视**，所以最后改成手扫字节
   （`hasLooseEq` / `hasLooseNe`：相邻字符判 `===`、`!==`）。针 19 里配了负对照：
   `=== / !==` 的合规范写法**不许**命中 —— 只会红的尺子和只会绿的尺子一样没用。
2. **`imports` 那一格两义**：页面上印的是"import 1 条"，而那份 Python 片段实际有两条导入 ——

# W9 截图件：拿到像素的那条路，和它顺手抓出来的一个假绿

## 为什么要动产品代码去拿像素

验收那句是"真开页面跑完整圈并**留截图读数**"。in-app 面板的 `take_screenshot` 要他把面板开到前台（我不代做），
所以本机零成本的出图路只有 Edge 无头：`msedge --headless=new --screenshot=… --window-size=…`。
但无头出图不会点按钮 —— 于是加了一个入口：**`?run=1` 打开页面就自己跑一圈**。

这不是造数据：它调的是与点【发起一发】完全同一条 `/api/turn`，跑的是同一份内核接缝。
它造的是**触发方式**。所以页面上必须自己写清楚：`这一发由 URL 参数 ?run=1 自动触发（不是人点出来的；代码与栈用的是页内置样例）`，
这句话写在 `#autorun`（默认 `hidden`），由 JS 打开。针 22 钉的就是"悄悄跑"这个危害。

## 这一轮真值最大的一条：旧探针在量空气（"四档断点 overflow 0" 那句作废）

旧 `工具/a11y_probe.js` 的 iframe 只带 `?probe=W` —— 那份页面**没跑过**：结论带是空的、九步不存在、卡片一条没有。
空页面当然不溢出。所以归档里"四档断点 overflow 全 0"量的不是有人在看的那一份。
把 iframe 换成 `?probe=W&run=1` 并等九步亮齐之后，**同一份 CSS 量出了真溢出**：

    320px → 208px 溢出；360px → 168px；390px → 138px；768/1024/1440 → 0px
    （每档 trace=13 项、band=238 字 ⇒ 量的确实是跑完的那一发）

撑宽的不是版面，是**不可断的长串**：`python:text(bare-except,except-pass,…)` 这类判据名落在 `#decisions li` 与 `.dim` 里
（实测 `DIV.dim` scrollWidth 476 / clientWidth 303；`UL#decisions` 489 / 325）。
修法一条：`header, header *, main, main * { overflow-wrap: anywhere; }`。
改完重测：**320/360/390/768/1024/1440 六档全 0px**，`读数/W9-探针-真跑完那一份.json`（failures 0 条）。
旧归档 `W8-a11y探针.json` 不删，就地当"被取代的那一版"看（它那份是空页面量的）。

针 20 加了 ④b 守这一族：探针源码里必须有 `&run=1`、`#trace li`、`band_chars`、`offenders`，宽度表必须含 320 与 390，
CSS 必须有一条**覆盖 `main *`** 的 `overflow-wrap` 规则。
—— 最后这半条也是先红过才立住的：G 臂第一次**没咬住**，因为判据写成"文件里有没有 `overflow-wrap: anywhere` 这句话"，
而 `header` 那条规则里也有这句话，针就被无关出现满足了。改成按规则块解析、要求选择器覆盖 `main *` 之后，
G 臂（只留 header、摘掉 main）当场红。

## 这台机出图的一条边界（量法本身要交代）

试过 `--headless=new`、`--headless`（旧模式）、`--force-device-scale-factor=1`、`--hide-scrollbars` 四种组合，结果一样 ⇒
判定：**Chromium 在这台机上把窗口宽度夹在一个最小值上**（≥500）。
所以窄屏的读数只认 iframe 探针（它给的是真视口宽度），**不认这几张 320/390 的 PNG**；
528 与 1440 这两张在夹值之上，可以当排版证据。

| # | 问题 | 修法 | 为什么这样定 |
|---|---|---|---|
| 1 | 失败被吞 | `DeclFail []string` 收进 `SeamReply`；第 7 步那句话点名"有 N 格没落账"+ 未决区加一条 `absent` 带内核原话 | 声明没落账 ⇒ `readers_report` 说这格没人读，我们却喊"读了 12 格"：两边各说各话就是假账 |

## W13：验收复跑件（02:29 → 02:33）—— 把"我在会话里跑过一遍"变成"一条命令再跑一遍"

第 ⑩⑪⑫ 步只能记「这一步没东西可印」。那三个是**只读件**，数的是那本账、不是这一发进没进账：
账还在原地，内核照样答得出。⇒ 抽出 `收口数(rpc, &rep)` 挂在四条早退路上；
唯一不打的形状是 check_call 本身没回话（通道断了三个调用也一样死，编不出数）。

**「没落账」仍然要看得见**（这是这一改最容易翻车的地方）：被挡那一发现在带内核五档原话，
但 ⑤ 跑、⑥ 没跑带门口原话、⑦ 没跑带理由、KPI 是量到的 0、budget_over 在 —— 针 21 把这五条钉在一起，
外加一条反向牙：未决里不许再挂「收口读数拿不到」（那三个既然跑了，这条就是**假未决** = 把已量说成欠账）。

**判据又抓到我自己一句白话**：新加的「接缝报散」那一形上屏是光秃秃的「没读回：」——
那条路上代码只看 `reply.Reason`，把 `err` 丢了。⇒ 抽出 `缺席理由(Reason → err → Verdict → 明说没有)` 给 ⑥⑦ 共用。

**副作用两条，一好一坏都记**：
- 好：W37 那两条「守卫臂」（被挡那发让链上长了 / 被拒计数对不上）从此有活体 —— 被挡那发带着链上与被拒读数进场。
- 坏：traceSane 第 6/9 条的活体形状少了（noClose 只剩调用失败才走）⇒ 给针 41 补「接缝报散」「收口没回话」两形当证人，
  并加三条牙点名"两句缺席理由不许互相冒充"。

**chainSane 第 3 条被真相反驳**：我原来判「被挡一次 ⇒ 内核的被拒写入该 +1」，账满那一形当场被它判红 ——
「被拒的写入 N 次」是**内核判据**的计数，外壳按部署方容量挡下的那类不走它（那句拒收原话自己就写着"不是内核判据拒的"）。
⇒ 改成只判两个方向：一发最多让计数走一步；走了一步的那发必须真是一次拒收。

**闸 2b 立刻报了两句真话**：G9/G10 两臂恒绿 —— 它们打的是 noClose 那条路，⑨ 真跑之后超预算这一形不再走那儿。
⇒ 换目标重打：G9 打「早退路上不打量」、G10 打「那一格被换名字」；12/12 臂重新全咬、空臂 0、还原后 rc=0。
