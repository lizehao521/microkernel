- [证据六条规矩](feedback-evidence-rules.md) — 红不了的承诺是散文；数自印+逐名归因；三态不塌；全绿先证尺子会红+配反臂；**状态要跨落盘往返、剔除类要扫成品、端口"有人在听"先验 owner、反臂子发必须是叶子、"最新"只按 mtime、声称的处置要带回处置后读数、结构类针要数标签配平+用刚编的产物+破缓存、**数不存在的东西得到的 0 ≠ 真的没有（对照的预期红单独记账，恒红的尺子也没牙）**、跨进程别比字节（时钟刻度=抖动源，比内容字段+掩码逐名打印+反臂证掩码不吞）、跨件传数要一行结构化字段（别 grep 散文）、改前端要配结构针+屏幕脏字栏、失败读数要能自证为什么、别猜引擎规则去问引擎（min-content）+等待要等"要断言的那个东西本身"、取字节对账前先看 HTTP 状态码/改完按语义数一遍、**对照臂要"产品字节=修前、尺子字节=修后"（同源取字节重编，两臂各印长度当凭证）**、**多判据的针红了要点名是哪一条在响**、**声称"产出了文件"要带回文件本身读数（file/字节/肉眼开图），rc=0 不算证据**、**新写的口径句第一次上屏要当读者读一遍；不同口径的两个数不写进同一句（M=0 别说成有东西）**、**给新闸配臂：改"报告出来的数"不算造出现场，臂要让两个读数真打架（新闸先问它看不见什么）**；**跑的是哪一份 build 要打印 exe 哈希 + 比 served 字节**；**"缺席"分两种：该有而没有 ≠ 本来就没这回事（没这回事的格别挂成未决）；为某形写过的分支没有一发走过 = 没量过**、**新判据先在真发矩阵上跑，红了先怀疑判据（别改产物迁就它）；上屏的数与算数的时机同源；判未决要扫 why_absent 不是条目名**、**新旗标要留第三态（旧记录=没量过，不是真不是假）；bool+omitempty 会吃掉 false、真值判断会把 nil 塌成红**、**跨发的数按增量对，别拿绝对值（绝对值可能数的是整个进程那本账）；拿绝对值前先问这个数是谁的**、**行为一改先去问臂还打在不在原来的坏法上（恒绿＝没牙，搬目标不删臂）；截图逐字节相同只证「看得见」不证 build；只读件跑了就不许再挂假未决**、**从别人的结果取数先确认过滤字段真存在（不存在的字段会把全量判成不合格＝假红）；派生计数落盘前先造一次该红的现场；字段名要写清算的是字节还是码元**、**判据/臂里的字符串匹配要盯"那一步的那句话"（汇总行里的计数词含关键字 ⇒ 恒过）；规则只管单向时名字就是覆盖边界**、**布局判据要 top 聚类 + 配单列臂（拿"top 相等"和"容器高+2px"都误判过）；后端全绿≠页面活（零构建前端的 node --check 要进同一条验收命令）；窄屏的图不算几何证据（headless 画布比 CSS 视口窄，右边被裁）；一格一份、别处引用格名不抄正文；写死的道数会随闸增减说谎（要现数）**、**旗标/钩子/基线三类都要自证接了线（`Array.isArray(字符串)` 恒 false 让 `--only` 从没生效；决定覆盖面的钩子不能可选；取错字段名会被 JSON.stringify 静默吞掉=钉了个空；空集 reduce 初值是假数）**、**配臂先证"臂接在被改的那个绑定上"（改 module.exports 而内部走本地调用＝恒等假变异；改 exports.x 而末尾换了 module.exports＝判据全红）；非法样例要长到不触发前置校验，否则被测那条永远轮不到**、**两个自印分母要互相对账（符号可核 N≠`refs total` ⇒ 有槽没进档）；改判据件先问新分支挂在哪个类型判断下；返回字典查重键；自证臂有没有牙看清单对数不看 rc**
