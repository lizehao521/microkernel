## 相对 v1 的关键变化

- 判断为**功能市场**，不是平台市场；SAM 下调至 1.0–2.0 亿美元，SOM 0.5–4.0 百万美元。
- 可防守差异是**证据包规范、拒收计数、版本三元组、R/N 协议**，不是哈希链或 49 格。
- 新增 **G1.5 闸**（第 90 天，10 例 R/N 双臂：R 臂留出集通过率 ≥ N 臂 +20 个百分点，假修复率不高于 N 臂）。
- 定价改为按证据包/年费：社区版免费、团队版 1.5–3.0 万美元/年、证据包版 4–8 万美元/年、试点 3–5 千美元/6 周。
- 财务基准（C 级）：Y3 收入 50 万美元，三年累计收入 65.9 万、净现金流 53.9 万美元。

## 记录面事实（本机实测，附录 B1）

2,941 行 = 1 行前言 + 2,940 条记录；60 次调用 × 49 格；12 会话；4 个自报 actor；
链 `seq/prev/payload/seal` 2,940/2,940 重算通过；但产物内容字段 0/2,940、
无版本/判据字段、无拒收计数、无闸门行、无签名；`read_back` 不返回指纹；
`declare_reader` 仅内存；`load_journal` 可整本替换（`APPEND_ONLY` 默认关闭）。
结论：**记录完整 ≠ 内容为真；账本本身不构成闭环。**
