07推荐路线与五道闸

问题：D + A 先行走多远？什么读数出现时必须停？B 到底要等到哪一步？

7.1 四条原则

  1. 先证据，后收入。没有外部复核的证据包，不进入销售。
  2. 先附着，后替代。接入现有 trace / eval，不做另一个平台。
  3. 先私有，后托管。当前只做本地 / VPC 证据包；托管按次不做。
  4. 先证伪，后承诺。每个阶段都写“什么读数出现就停”，不写“预计会成功”。

7.2 三个阶段与交付物

阶段 D（第 1–6 周）：研究出版。发布《Agent 执行 → 项目记录 → 二次修改》报告、R/N 协议、负结果与证据包规范草案。 目标不是流量，是 3 个外部评审意见、1 个愿意做 POC 的团队、1 个真实触发（事故复盘 / 审计 / 行为变更）。

阶段 A（第 7–14 周）：开源证据适配层。发布 OTel / LangSmith / Langfuse 适配器、证据包模板、10 例失败样本。 目标是 3 个非作者团队各自产出 1 个证据包，并完成 1 次可复核修改；不是 star 数，也不是下载量。

阶段 B（第 19–26 周）：企业私有化。只在 Gate 1.5 与 Gate 2 都通过后启动。交付 VPC / 本地部署、SBOM、DPA、责任边界与安全审查材料； 目标是 2 封 LOI + 1 次安全审查 + 1 个付费试点。阶段 B 不追求“多客户”，追求“第一个能续费的客户”。

7.4 停止条件与退出

  • G1 连续两次不过：停止开源推广，回到适配层与样本质量；不做销售。
  • G1.5 连续两次不过：冻结为研究资产 C；保留报告与规范，不保留商业承诺。
  • G2 没有 LOI：降级为咨询 / 研究合作；不做私有化产线。
  • G3 没有续费：停止扩张；保留 1–2 个深度客户，转做定制证据包。

7.5 未来 7 天做什么

  • 发布研究报告与 R/N 协议草案；邀请 3 个外部评审，不买流量。
  • 建 `evidence/` 模板：账本、原像、版本、拒收日志、外部验证结果。
  • 从现有报告挑 10 个失败样本 + 10 个留出样本，冻结清单。
  • 写 G1.5 的预注册判据：主指标、假修复率、盲评方式、反臂 A/B。
  • 做一次内部 dry run：非作者同事 60 分钟产出证据包；记录卡点。
  • 准备 3 个复盘工作坊问题，不做产品演示。
  • 把“闭环 / 30 分钟 / 防线 / 合规认证”四个词从对外材料里删掉。

08定价与单位经济

问题：证据包按什么计价？为什么不能按 seat / span / token？单位经济在什么条件下成立？

8.1 计价单位：证据包，不是调用量

可观测性平台按 seat、span 或数据量计价 [16][17][19][20]；评测平台按 experiment / 样本量计价 [18]。 证据包的价值不在“记录了多少”，而在“能不能支撑一次修改、能不能回滚、能不能对外披露”。因此计价单位应是 “每年证据包订阅”或“每次可复核修改”，而不是 seat / span / token。按调用量卖，会把证据层拉进可观测性的价格战； 按人头卖，会把价值锚在“人头”而不是“风险”。

8.3 单位经济：支持天数是生死线

证据包不是纯软件：私有化部署、安全审查、审计陪同都要人力。按团队版 ARPU 1.8 万美元、年支持 3 天、每天成本 800 美元估算， COGS 约 2,400 美元，毛利率约 87%；证据包版 ARPU 6 万美元、年支持 10 天、每天 800 美元，COGS 约 8,000 美元，毛利率约 87%。 如果支持天数翻倍，毛利率会掉到 75% 以下；如果客户要求 7×24 响应，单位经济不成立。

8.4 定价风险与规则

  • 平台捆绑：可观测性平台把证据功能打包，价格被压到“功能价”；对策是卖“跨平台 + 可披露 + 可回滚”，不卖单点功能。
  • 买家拿日志存储比价：证据包不是存储；报价时把“一次事故复盘的成本”作为锚，不用 GB 单价。
  • 采购上限：团队版落在 2 万美元以内，绕过部分审批；证据包版走安全预算。
  • 折扣纪律：试点可以打折，年度不送私有化；不做终身买断。

8.5 定价结论

价格锚在“证据”，不在“量”。团队版 1.5–3.0 万美元 / 年负责获客；证据包版 4–8 万美元 / 年负责收入；试点 3–5 千美元 / 6 周负责验证。 如果客户只愿意按 span 付费，说明他买的是可观测性，不是证据包；这类客户应转给平台，不进入销售漏斗。
