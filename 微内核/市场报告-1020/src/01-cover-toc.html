Reading Guide

这份重评怎么读

v1 回答的是“五条路先走哪条”。v2 回答的是“在上一轮研究证明账本本身不构成闭环之后，这条路还成不成立、要不要改”。

一句话结论

D + A 先行，但 A 的交付物变了

研究出版（D）仍然第一，因为“执行记录能否支撑二次修改”这个类别还没有被外部复核过。 开源（A）仍然第二，但开源的不是“又一个账本”，而是证据适配层：把账本、产物原像、行为/判据版本与外部验证器装进一个可复核的证据包。 企业私有化（B）只在 Gate 1.5（R/N 双臂）与 Gate 2（LOI + 安全审查）都通过后触发；托管按次（C）不做；竞赛/生态（E）可选。

三条边界，先写在前面

边界含义不允许的读法
审计层不是防线agentkernel 记录、读回、验链；不拦截、不调度、不联网、不执行工具。“上了内核就挡住了提示注入 / 工具滥用。”
记录完整 ≠ 内容为真哈希链证明账未改；不证明账里的内容可信、出处可靠。“verify 通过，所以结论可信。”
闭环尚未实证R/N 双臂与两条反臂都未跑；严格双臂判据仍是 FAIL。“看记录再改已经证明有效 / 闭环已通。”

证据分级：五种状态，不许塌成一种

等级定义本报告怎么用
A工具自印 + 独立复算，或双源逐字对上可直接支撑技术可信度与验收判断
B单一来源自印，未被本报告独立复算作为线索，标注“单源”
C作者复算 / 规划假设，无原始件用于数量级、情景与设计，不读成调查结论
D外部公开资料，注明访问日用于背景、法规、竞品与价格锚
X不可核 / 未验证写“不知道 / 未跑”，不塌成 0

与 v1 的关系

v1 的市场规模、竞品价格锚、法规背景仍然可用；v2 不重复铺陈，只改三件事： 产品叙事（从账本改为证据包）、进入门槛（新增 Gate 1.5）、规模与财务（因“功能而非平台”下调）。 如果你只读一页，读第 0 章的“变了什么”表。
