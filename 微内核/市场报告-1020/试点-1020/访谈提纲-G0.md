## 2. 对象与资格

### 2.1 三条访谈线

| 线 | 角色 | 关心的问题 |
| --- | --- | --- |
| A 买家发起人 | AI 平台负责人 / AI 工程负责人 / 模型风险负责人 | 这次变更为什么发生、是否真的更好、谁签字 |
| B 安全工程 | 安全工程 / 事件响应 / AI 安全 | 事后取证、日志能证明什么、数据条款 |
| C 合规 / 风险 | 模型风险 / 审计 / 合规（不提供法律意见） | 留什么证据、可审计与认证的边界 |

### 2.2 必须满足

- 本人拥有或能影响 AI 变更评审；
- 过去 90 天见过至少一次 AI 行为变化；
- 能说出一个**非作者**的复核人（可以暂时匿名）。

### 2.3 直接排除

- 要“认证 / 防线 / 零风险 / 保证不出事”；
- 没有真实修改，只想看材料；
- 没有非作者复核人，或复核人就是作者；
- 拒绝数据驻留 / 留存 / 删除 / 子处理方条款；
- 要求我们调用模型、改客户代码、接运行时；
- 只有采购流程，没有技术或风险角色。

> 排除也是结果：记 `disqualified` 与原因，不计入 10 次有效访谈。

## 3. 30–40 分钟脚本

### 3.1 开场（3 分钟）

1. 说明目的：研究“真实修改后如何独立判断”，不是卖产品；
2. 说明非声明：不证明系统安全、合规、模型正确、零风险；
3. 征求笔记许可；录音需书面同意，未同意只记要点；
4. 说明可随时跳过问题、可要求删除记录。

### 3.2 角色与上下文（5 分钟）

- 你负责什么范围？最近一次 AI 变更是什么类型？
- 你们团队一年大概有多少次行为变更（模型 / 提示词 / 路由 / 工具 / 阈值）？
- 谁最终说“这次改好了”？

### 3.3 真实修改复盘（10 分钟，核心）

必须落到**一个具体案例**，不接受泛泛而谈：

1. 最近一次 AI 行为修改是什么？什么时候？
2. 改前 / 改后分别是什么？现在还在吗？谁保管？
3. 当时怎么判断改好了？有没有同题对照 / 留出集？
4. 谁复核的？他和作者是同一个人 / 同一团队吗？
5. 复核用了多久？结论是什么？有没有拒收过？
6. 如果今天让你在 60 分钟内复核，你会卡在哪一步？
7. 这次修改如果出了问题，你们能拿出来证明“改的是哪一版”吗？

**追问**：
- “有改前 / 改后的哈希吗？没有的话，怎么知道拿的是同一份？”
- “模型版本、路由、阈值、工具集，哪一版？来源是部署记录还是模型自报？”
- “拒收记录在哪里？分母是多少？”

### 3.4 现有工具与工作替代（5 分钟）

- 你们现在用什么 trace / eval / 发布系统？
- 它们能回答“发生了什么”，那么“这次修改凭什么算数”由谁回答？
- 现在最常用的替代办法是什么：周会、人工比对、作者自述、还是不查？
- 这个替代办法最坏的一次结果是什么？

### 3.5 评审与签字（5 分钟）

- 通过 / 拒收 / 超时，三态里你们实际用哪几种？
- 谁有权签字？签字人需要看到什么才会签？
- 什么证据你会认为是“作者自说自话”？
- 如果复核人 60 分钟做不完，你们会延期还是直接拒收？

### 3.6 数据与安全（5 分钟，B / C 线重点）

- 数据驻留：本地 / 客户环境 / 云？有没有硬要求？
- 留存多久？到期删除谁批准？要不要删除回执？
- 有没有子处理方限制？
- 密钥怎么处理？能否接受只在环境变量、绝不进包 / 进账？
- 日志里可能有个人信息 / 口令，脱敏规则谁确认？
- 只读旁挂、不接运行时、不改代码，这个姿态能接受吗？

### 3.7 预算与下一步（5 分钟）

- 如果做一次 6 周试点（3–5 千美元），走哪个预算科目？
- 采购需要哪些材料：安全审查、DPA、SBOM、责任边界？
- 谁会是 POC 的发起人？谁指派复核人？
- 什么情况下你会直接说“不做”？
- 下一步最小动作是什么：介绍复核人 / 给一次脱敏样本 / 看一页说明 / 不跟进？

## 4. 分线补充问题

### 4.1 买家发起人

- 你向上汇报时，最怕被问哪三个问题？
- 如果只能保留一件证据，你留什么？
- 你愿意为“可复核”多花多少流程时间？上限是多少？
- 试点失败时，你希望报告怎么写？

### 4.2 安全工程

- 一次 AI 变更后，安全最需要回答的三个问题是什么？
- 现有日志能证明什么、不能证明什么？
- 取证链里哈希、custody、时间戳，哪个是硬门？
- 如果证据包不覆盖 MCP01/03/06，只覆盖审计日志（MCP08），你能接受吗？
- 出现安全事件时，这份包能不能作为复盘材料？缺什么？

### 4.3 合规 / 风险

- 你们需要留什么证据给审计 / 监管？不需要什么？
- “可审计”和“认证”的边界在哪里？
- 模型自报的版本 / 用量，你们会采信吗？需要什么独立来源？
- 拒收记录与分母是否属于必须留档？
- 30 天留存、5 天删除是否可行？谁批准？
- 如果我们明确写“不证明合规”，你们还会用吗？
