**判定**：

- S1、S2、S4、S7 任一为“否” → `ineligible`，不计入有效访谈；
- 任一硬项“说不清” → `hold`，补一次确认，不先约访谈；
- 软项“说不清” → 可约，但访谈中必须问到，未问到记 `absent`；
- 全过 → `eligible`，进入预约。

> 排除也是结果：记 `ineligible` 与原因；不把排除原因改写成“暂时不方便”。

## 5. 状态机与计数口径

| 状态 | 定义 | 计入有效访谈 |
| --- | --- | --- |
| `identified` | 只进了池子，未联系 | 否 |
| `contacted` | 已发出一次邀请 | 否 |
| `replied` | 有回复，未定时间 | 否 |
| `qualified` | 资格全过，待约 | 否 |
| `scheduled` | 已有明确日期与时长 | 否 |
| `completed` | 访谈已发生 | 否 |
| `effective` | 目标角色 + 谈过一次真实修改 + 留下可跟进项 | **是** |
| `not_effective` | 访谈发生，但无真实修改 / 无下一步 | 否 |
| `ineligible` | 硬项不过 | 否 |
| `declined` | 明确拒绝 | 否 |
| `no_response` | 两次跟进后仍无回复 | 否 |
| `cancelled` | 约好取消，未重约 | 否 |

**分母纪律**：

- 有效访谈分子只数 `effective`；`completed` 不等于有效；
- `ineligible` / `declined` / `no_response` 计入接触分母，但不计入 10；
- AI 模拟访谈、作者自问自答、同事代答：一律不计，记 `not_effective` 并注明；
- 没有记录 = `NOT_RUN`，不写 0，不写“已覆盖”。

## 6. 联系与预约（话术可直接复制）

> 首次接触只约 15 分钟资格通话（见 `G0-资格通话-15分钟.md`）；三项全过后，再用 6.1 的话术约 30–40 分钟深访。

### 6.1 初次邀请（短消息，可直接复制）

> 你好，[称呼]。我在做一项“AI 行为修改后如何独立复核”的研究，不是卖产品，也不报价。想约 30–40 分钟，聊一次你们过去 90 天真实发生过的 AI 变更（模型 / 提示词 / 路由 / 工具 / 阈值）。重点不是评价好坏，而是：改前改后是否拿得到、谁复核、60 分钟内能不能复核完。  
> 我不会调用你们的模型、不改代码、不接运行时；笔记只存本机，30 天内删除，可随时要求删除；不录音除非你书面同意。不方便的话直接拒绝也没关系。愿意的话，回一个可用的 30 分钟时段即可。

**发送前核对**：对方属于 A / B / C 线之一；不群发；不附报价；不承诺认证 / 防线 / 零风险。

| 项 | 内容 |
| --- | --- |

### 6.3 跟进上限

1. 首次邀请后 **3 个工作日**无回复，跟进 1 次；
2. 再 **3 个工作日**无回复，记 `no_response`，不再追；
3. 每人最多 **2 次**主动联系；不群发、不换渠道轰炸；
4. 访谈后 **24 小时内**填 `访谈提纲-G0.md` §5，原话保留；
5. 每周五汇总一次 §7，只报计数与原话，不报“感觉很好聊”。
