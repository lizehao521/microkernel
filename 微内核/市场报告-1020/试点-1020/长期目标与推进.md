## 1. 长期目标（180 天）

**一句话**：到 **2027-04-18**，把 Agentkernel 从“一次可控试点的设计”推进到“可重复交付的证据包服务”。

“可重复交付”必须同时满足六条，缺一条都不算：

1. 至少 1 个真实客户的真实修改：改前 / 改后产物、SHA-256、custodian、时间齐；
2. 至少 1 名**非作者真人**在 ≤60 分钟内完成复核，给出通过 / 拒收 / 超时三态之一；
3. 每次拒收有 R1–R7 码、有分母、有样例；
4. 10 例 R/N 双臂：R 臂通过率 ≥ N 臂 +20pp，假修复率不高于 N 臂；
5. 2 封 LOI + 1 次安全审查 + SBOM / DPA / 责任边界；
6. ≥3 家付费 ≥1 万美元，或 ≥5 家付费试点；≥1 家续费 / 转正。

**做不到第 4 条**：按停止规则冻结为研究资产 C，不再对外销售。  
**做不到第 5–6 条**：保留服务能力，不宣称“可复制 / 可规模化”。

## 6. 停止规则（先写死）

1. 无真实修改样本 → 不签；
2. 无原像 / custody → 不封包；
3. 无版本三元组 → 不封包；
4. 无非作者复核人 → 不受理正式复核；
5. 复核超时 → 记 R6，不替作者解释；
6. R/N 样本不足 → 只写 `NOT_RUN`，不写“有提升”；
7. G1.5 连续两次不过 → 冻结为研究资产 C；
8. 客户要求“认证 / 防线 / 零风险” → 不接，改范围或退出；
9. 任何密钥 / 口令进账 → 立即停止，按安全事件处理；
10. 过度声明 → 发布前逐条对照非声明清单，删掉不能证明的句子。
