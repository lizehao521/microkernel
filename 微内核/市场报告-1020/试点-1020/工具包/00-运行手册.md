# 试点工具包 · 运行手册

- **版本**：v1.0（2026-10-20）
- **依据**：`产品设计-1020/产品设计蓝图.md` §3 服务蓝图、§8 证据包规范、§10 试点运营
- **适用**：Agentkernel 证据包服务的一次真实试点（单客户、单次修改、单名非作者复核人）
- **本文件不是**：报价、合规意见、安全认证、交付承诺。未发生的外部动作一律 `NOT_RUN`。

---

## 0. 这套件怎么用（按顺序）

| 步 | 文件 | 谁填 | 产出 | 卡点 |
| --- | --- | --- | --- | --- |
| 1 | `01-受理单.md` | 证据工程师 + 客户发起人 | 受理 / 拒绝线索 | 原像、复核人、数据条款任一缺 → 不受理 |
| 2 | `02-证据包清单.md` | 证据工程师 | 8 段完成度表 | 硬门任一红 → 不封包，只能草稿 |
| 3 | `03-复核工作台.md` | 非作者复核人 | 复核记录（通过 / 拒收 / 超时） | 超 60 分钟 → R6 |
| 4 | `04-拒收账.md` | 证据工程师 | R1–R7 计数 + 分母 + 样例 | 无计数 → 不得对外称“有复核” |
| 5 | `05-POC报告模板.md` | 证据工程师 | 报告（草稿 / 可发布） | 无复核记录 → 只能草稿 |
| 6 | `06-数据与安全清单.md` | 证据工程师 + 客户安全 | 条款确认 + 删除回执 | 无条款 → 不签约 |

**运行顺序不可跳**：先受理、再组包、再复核、再报告。任何一步想跳，停下来记原因。

## 1. 角色与边界

| 角色 | 能做 | 不能做 |
| --- | --- | --- |
| 客户发起人 | 提供原像、版本、复核人、数据条款 | 代替复核人下结论 |
| 证据工程师 | 受理、组包、链验证、写报告草稿 | 替客户补原像、替复核人判定 |
| 非作者复核人 | 按 S1–S6 独立复核、给出三态决定 | 是作者 / 同团队成员；接收作者口头解释 |
| 作者 | 提供账本与工具说明 | 参与判定；在复核现场解释；修改客户模型代码 |
| 安全 / 合规 | 审数据条款、留存、删除 | 把“看过条款”写成“认证通过” |

> 最小可行配置：1 名证据工程师 + 1 名非作者复核人 + 客户发起人。缺复核人 = 不受理。

## 2. 七个阶段与时限

| 阶段 | 时限 | 输入 | 输出 | 停止规则 |
| --- | --- | --- | --- | --- |
| 0 触发与资格 | 15 分钟通话 | 客户描述 | 资格记录 | 无真实修改 / 无复核人 / 不接受条款 → 不进入受理 |
| 1 受理 | 受理会后 3 个工作日 | 原像、版本、复核人、条款 | 受理记录 + 原像清单 | 第 3 个工作日仍缺 → 停止或降级 |
| 2 组包 | 受理后 10 个工作日 | 账本导出、版本、拒收账 | 包 v0.1 + 链验证 | 链断不可修 / 原像缺 / 版本缺 → 不封包 |
| 3 预演 | 组包后 2 个工作日 | 包 v0.1 | 预演记录 | 两轮 >60 分钟 → 改清单，不承诺 60 分钟 |
| 4 正式复核 | 60 分钟（单次） | 包 v1.0 | 复核记录 + 决定 | 超时 → R6；复核人缺席一次可延期，再缺 → 停 |
| 5 R/N（可选） | 复核后 5 个工作日 | 同题样本 ≥10 | R/N 表 | 样本 <10 → `NOT_RUN`，不宣称增量 |
| 6 报告与收尾 | 复核后 3 个工作日 | 复核记录 + 度量 | 报告 + 删除回执 | 无复核记录 → 报告只能标草稿 |

**总时长目标**：受理到报告 ≤ 6 周。超时不是“再等等”，要在缺口清单里写清卡在哪一段。

## 3. 硬门（不可协商）

封包前逐条打勾；任一条否，包状态只能是 `draft`。

1. 范围与非声明已写，客户确认过“不证明什么”；
2. 改前 / 改后产物各有 SHA-256 + custodian + 时间；
3. 版本三元组 3 / 3 有来源（产物版、行为版、判据版）；
4. 账本切片链自洽（seal、prev、anchor 三项复算通过），断点可定位；
5. 拒收账有 R1–R7 计数与分母（0 也要写 0 / N，不写空白）；
6. 复核记录有具名非作者、独立性声明、S1–S6 用时、三态决定；
7. R/N 样本 ≥10 才写增量，不足写 `NOT_RUN`；
8. custody / 留存 / 删除 / 子处理方条款已签。

> 第 1–4、8 条缺 → 不封包。第 5–6 条缺 → 只能草稿。第 7 条不足 → `NOT_RUN`。

## 4. 证据分级（写进每个字段）

| 级 | 含义 | 允许的写法 |
| --- | --- | --- |
| A | 工具自印 + 独立复算一致 | “49 / 49，复算命令见附件” |
| B | 单一来源自印，未独立复算 | “账本自报 2,940 条（未复算）” |
| C | 计划 / 假设 / 推演 | “计划 60 分钟（未跑）” |
| D | 外部公开资料 | 注明出处与日期 |
| X | 未发生 / 未测 | `NOT_RUN`，不写 0、不写空白 |

**三条铁律**：
- 没量到 ≠ 0；没发生 ≠ 失败；有模板 ≠ 有客户。
- 任何比率必须带分母；分母为 0 时写 `NOT_RUN`。
- 作者自测只能标 B；A 级必须有独立复算命令与输出。

## 5. 停止规则（现场版）

1. 客户拿不出改前产物 → 不受理（R1 / R2），不当场“想办法”；
2. 复核人是作者或同团队 → 不受理（R5）；
3. 链复算失败且 30 分钟内定位不到 seq → 停止组包（R4）；
4. 复核 60 分钟未完成 → 记 R6，不替作者解释、不延长计时；
5. 客户要求“认证 / 防线 / 零风险 / 保证不出事” → 改范围或退出；
6. 发现密钥 / 口令进入材料 → 立即停止，按安全事件处理，不写入任何包；
7. R/N 样本不足 → 写 `NOT_RUN`，不写“趋势向好”；
8. 报告出现无法用包内证据支撑的句子 → 删除或降级为 C。

## 6. 一次试点的最小记录集

- 受理单（含原像清单、版本三元组、复核人具名、条款）；
- 账本切片 + 校验 JSON（含复算命令与版本）；
- 8 段完成度表（每段：present / absent + 理由 / `NOT_RUN`）；
- 复核记录（计时、S1–S6、决定、断点）；
- 拒收账（分母 + 样例）；
- 报告（草稿或可发布）+ 非声明清单；
- 删除回执（若客户要求删除）。

缺任何一项，试点不算完成，只能算“进行中”。

## 7. 常见误写（发布前自查）

| 误写 | 改成 |
| --- | --- |
| “链 100% 通过” | “本切片 49 / 49 复算通过；客户包 `NOT_RUN`” |
| “复核通过” | “1 名非作者复核人，58 分钟，决定=通过；样本 1 例，不外推” |
| “R/N 提升 30%” | “10 例，R 80% vs N 50%，+30pp；验证器与样本见附件” |
| “已删除” | “5 天内删除，清单 N 项，回执哈希 …” |
| “安全” | “本次未发现密钥入包（扫描命令与输出见附件）；不构成安全认证” |
| “零风险” | 删除。改为具体边界与非声明 |
