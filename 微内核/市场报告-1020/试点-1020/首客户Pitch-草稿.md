# 首客户 Pitch · 证据包试点（草稿）

- **日期**：2026-10-20
- **状态**：草稿；**尚未对任何客户使用**；G0 访谈 0 / 10
- **受众**：AI 平台负责人、安全工程负责人、合规 / 风险负责人
- **证据等级**：产品机制 A（本地样本包可复算）；市场假设 C（未访谈）；客户证据 X（`NOT_RUN`）
- **不是**：报价、合规意见、安全认证、交付承诺

> 本 Pitch 只提出一个可被拒收的试点，不证明市场需要。没有 G0 访谈记录，所有“客户会……”都是假设。

---

## 1. 一句话押注（The Bet）

> 我们押：**一次真实 AI 修改 + 8 段证据包 + 一名非作者 60 分钟复核**，能在 6 周内把“这次改好了”从作者自述变成可复核结论。

**成功标准（只认这一个）**：1 个真实包 + 1 名非作者复核人 + 通过 / 拒收 / 超时三态之一 + 断点可定位。

**不把以下当成功**：链自洽、页面好看、AI 模拟读者高分、报告写完但没人复核、作者自己说“改好了”。

---

## 2. 为什么是现在（Why Now）

> 以下均为待验证假设（C 级），不是访谈结论。

- **变更频率在上升**：模型、提示词、路由、工具集、阈值都可能改；但“改的是哪一版”仍常靠作者记忆。
- **现有工具答“发生了什么”，不答“这次修改凭什么算数”**：trace / eval / 发布系统能给出日志与分数，但通常没有原像、版本三元组、非作者复核、拒收分母。
- **签字的人仍依赖作者自述**：模型风险、审计、安全复盘要证据时，团队拿不出“改前 / 改后 + 谁复核 + 为什么通过”。
- **窗口**：大厂 observability 继续做“发生了什么”；“AI 承诺算不算数”的独立复核包仍是空位。这个判断需要 G0 验证，不是既成事实。
- **现在不做的代价**：每次变更继续用周会 / 人工比对 / 作者自述；拒收没有码、没有分母；下一次审计仍从零开始。

---

## 3. 我们为谁设计（User & JTBD）

**林（代称，persona 假设，不是真实客户）**，AI 平台负责人，团队 20–200 人，过去 90 天至少经历一次模型 / 提示词 / 路由变更。

**JTBD**：当一次 AI 行为变更要上线，我想让一个非作者在 60 分钟内独立判断“改的是哪一版、证据是否成立”，从而在签字时不必只依赖作者。

**次要角色**：
- 安全工程负责人：事后取证与复盘；
- 合规 / 风险负责人：留可审计证据，但不要求我们做认证；
- 非作者复核人：按 60 分钟工作台给出三态决定。

**不服务**：要“认证 / 防线 / 零风险 / 保证不出事”的人；没有真实修改的人；没有非作者复核人的人；要求我们调用模型或改客户代码的人。

> persona 是假设；没有访谈记录前，不得写成“客户画像已验证”。

## 4. 方向与备选（Direction & Alternatives）

### 我们押的方向

**只读旁挂的证据包服务**：6 周试点、3–5 千美元、8 段包、非作者 60 分钟复核、拒收账、R/N 可选。不接运行时、不调模型、不改客户代码。

- **用户价值**：复核人不必听作者讲，按包内材料就能判断；
- **业务价值**：每次拒收变成可计数原因码，下一次组包更快。

### 考虑过的其他方向

| 方向 | 为什么不押 |
| --- | --- |
| B 可观测 / eval 平台 | 回答“发生了什么”，不提供独立复核、版本三元组、custody、拒收分母；且我们不做平台 |
| C 内部 wiki + 作者自述 | 最便宜，但复核人无法独立验证；作者既是运动员又是裁判 |
| D 认证 / 防线 / 零风险 | 不接；超出能力，也会把审计层伪装成防线 |

### 最大的不确定

**关键假设**：买家的瓶颈是“可复核性”，不是“可观测性”。

**怎么测试**：G0 10 次访谈，至少 3 次真实触发、1 个 POC 意向、1 个预算科目。如果多数受访者说“trace / eval 已经够了”，这个方向要改；如果拿不到真实修改或非作者复核人，试点不启动。

## 5. 关键设计决策（Design Decisions）

### 决策 1 · 8 段包 + 硬门，而不是一个 dashboard

缺原像、缺版本三元组、缺链、缺复核人 → **不能封包**，不是黄色警告。  
**证据**：`工具包/02-证据包清单.md`、`产品设计蓝图.md` §8；设计件 A，客户证据 X。

### 决策 2 · 三态不塌：有 / 缺席（带理由）/ 未运行

没量到的格写 `absent` + 理由，绝不写 0；没发生的事写 `NOT_RUN`。  
**证据**：样本包 5 个 absent 格（527 / 528 / 529 / 535 / 536）逐格有理由；A 级。

### 决策 3 · 60 分钟复核工作台，而不是无限期评审

S1–S6 分段计时，60 分钟到点即三态；超时记 R6，不替作者解释。  
**证据**：`工具包/03-复核工作台.md`；设计件 A，真人复核 `NOT_RUN`。

### 决策 4 · 只读旁挂，不接运行时

不调模型、不改代码、不拦截请求；只对已有日志 / 账本做证据整理。  
**证据**：产品边界；客户侧 0 改动 `NOT_RUN`（尚未在客户环境执行）。

### 决策 5 · 数据最小化：受控前缀，而不是整本账

完整账本含真流量时，包内只放**前缀受控副本**；作者侧已验证前缀与完整账本字节连续，但 custodian 绑定仍需确认。  
**证据**：`样本包-491-539/受控副本/`；前缀 539 / 539 A；custodian 签名 absent。

### 我们不做什么（写进合同前）

- 不证明系统安全、合规、模型正确、零风险；
- 不覆盖 MCP01/03/06，只对应审计 / 日志层（MCP08）；
- 不做模型质量排名、不做自动修复、不做托管按次；
- 不把“链自洽”说成“内容真实”。

## 6. 需要你决定的事（Asks）

### Ask 1 · 是否给一次真实 AI 修改（含改前 / 改后 + SHA-256 + custodian）？

- **为什么需要决定**：没有真实修改，8 段包只能做演练，不能算试点；
- **决定时间**：G0 访谈后 2 周内；
- **不决定的影响**：不启动试点；只能做内部样本演练，不计客户证据。

### Ask 2 · 是否指派一名非作者复核人，并在试点窗口给出 60 分钟？

- **为什么需要决定**：复核人是 G1 的硬门；作者本人复核无效；
- **决定时间**：试点启动前；
- **不决定的影响**：只能做内部干跑，不能宣称“已复核”。

### Ask 3 · 是否接受数据条款（本地只读、30 天留存、5 天删除、无子处理方、密钥只走环境变量）？

- **为什么需要决定**：条款不定，包不能签、数据不能收；
- **决定时间**：试点启动前；
- **不决定的影响**：不签约；无法受理原像与账本。

### Ask 4 · 是否指定试点预算科目 / 采购路径（6 周，3–5 千美元）？

- **为什么需要决定**：没有科目只能做免费演练，不能验证付费与续费；
- **决定时间**：G0 结束前；
- **不决定的影响**：不进入付费试点；G3 无法推进。

### Ask 5 · 是否同意“成功 = 三态决定 + 断点可定位”，而不是“AI 说更好”？

- **为什么需要决定**：否则范围会滑向模型质量、认证、零风险；
- **决定时间**：试点启动前；
- **不决定的影响**：范围失控，按停止规则退出。
