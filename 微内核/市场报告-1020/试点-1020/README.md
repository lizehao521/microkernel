## 6. 限制

1. 本包只有一次调用、一个会话，不能外推到其他流量 / 版本；
2. seal 通过只证明切片与账本一致，不证明调用内容真实或正确；
3. `payload_b64` 是值镜像，不是产物原件；
4. 49 条共用调用时间戳，不是逐格采样时间；
5. `model_says` 可无 source（当前实现只对 relayed / estimated 强制），复核人需单独标注；
6. 受控前缀只证明 seq 1–539 自洽；作者侧已验证前缀与完整账本字节连续，但完整账本含真流量、不随包分发，**复核侧 custodian 绑定仍缺**；

8. 没有客户、没有合同、没有付费；不得写“已交付 / 已验证 / 可规模化”。
