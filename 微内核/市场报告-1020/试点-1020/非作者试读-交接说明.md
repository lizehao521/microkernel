## 6. 可选复算命令

在解压后的目录内。Windows 解压请用资源管理器或 PowerShell `Expand-Archive`；Git Bash 自带的 `unzip` 可能把 UTF-8 文件名解成乱码（工具编码限制，不是包损坏，包内哈希仍一致）。

```bash

node 工具/切片与校验.js 样本包/受控副本/账本-前缀-1-539.jsonl 491 539 复算输出-anchor

# 验整段前缀
node 工具/切片与校验.js 样本包/受控副本/账本-前缀-1-539.jsonl 1 539 复算输出-prefix
```

也可以单独跑切片文件：

```bash
node 工具/切片与校验.js 样本包/链切片-491-539.jsonl 491 539 复算输出-slice
```

> 单独跑切片文件时，`anchor_link_ok` 会是 `false` / `null`，因为锚点 seq 490 不在该文件里；这**不是链断**。要验锚点，跑前缀账本 491–539。

没有 Node 也能复核：按 `样本包/证据包.md` §4.2 的 seal 公式，任取 1 条手算；手算结果写进记录。

> 作者侧 JSON 里的读数不是你的证据。至少独立复算 1 条，或明确写“无法复算 + 原因”。
