## 7. 变更控制

1. 任一脚本改动 → 重算 SHA-256 / 字节，更新 §2；
2. 改动影响复核包 → 重跑 `打非作者试读包.py`，zip 哈希会变，同步更新 README / `SHA256SUMS`；
3. 新增第三方依赖 → 本 SBOM 必须新增组件与许可证字段，不能沿用“0 第三方”；
4. 未更新 SBOM 的构建，不得对外称为“已附 SBOM”。
