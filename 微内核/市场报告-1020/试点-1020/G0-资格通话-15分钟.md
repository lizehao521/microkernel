## 1. 三项硬条件（只问这三件）

| # | 条件 | 通过 | 不通过 / 说不清 |
| --- | --- | --- | --- |
| 1 | **真实修改**：过去 90 天有一次 Agent 行为修改（模型 / 提示词 / 路由 / 工具 / 阈值），且改前 / 改后产物现在还在或可取得 | 有时间、有改动对象、产物可得 | 只有日志 / 只有口头描述 → `not_qualified`；说“要申请” → `hold` |
| 2 | **非作者复核人**：能指出一名与作者不同团队、不同人的复核人，原则上愿花 60 分钟 | 有具体角色 / 代号，关系清楚 | 没有 / 就是作者 / 同团队 → `not_qualified` |
| 3 | **数据条款**：接受本地只读旁挂、30 天留存、到期 5 天删除、无子处理方、密钥只走环境变量、不经第三方 SaaS | 明确接受，或仅待内部批准 | 明确拒绝任一硬项 → `not_qualified`；待批 → `hold` |

**判定**：三项全过 → `qualified`，约 30–40 分钟 G0 访谈；任一不过 → 停止；任一“说不清” → 只允许一次补充确认，仍不清即停止。

> `payload_b64` 是账本里的值镜像，不是改前 / 改后产物；只有日志不算条件 1 通过。

## 2. 15 分钟结构

| 时间 | 段落 | 做什么 |
| --- | --- | --- |
| 0–2 分钟 | 开场与非声明 | 说明是研究、不是卖产品；不证明安全 / 合规 / 模型正确 / 零风险；征求笔记许可；可跳过、可要求删除 |
| 2–6 分钟 | 真实修改 | 最近一次改了什么、何时、改前 / 改后是否还在、谁保管 |
| 6–9 分钟 | 复核人 | 谁会独立复核、与作者关系、能否拿出 60 分钟 |
| 9–12 分钟 | 数据条款 | 本地只读 / 留存 / 删除 / 子处理方 / 密钥 / 传输 |
| 12–14 分钟 | 下一步 | 三项全过 → 发决策卡 + 约 30–40 分钟；否则明确停止 |
| 14–15 分钟 | 复述确认 | 把三项答案读回给对方确认，避免记录偏差 |

**到点即停**。15 分钟后再展开，就变成了免费咨询。

## 3. 可直接照着问

### 3.1 开场（2 分钟）

> 我在研究“AI 行为修改之后，另一个人能不能独立复核”，不是卖产品，也不报价。今天只想用 15 分钟确认三件事：有没有一次真实修改、有没有非作者复核人、数据条款能不能接受。三项都成立，我再约 30–40 分钟细谈；不成立就到这里。笔记只存本机，30 天内删除；不录音除非你书面同意。

### 3.2 真实修改（4 分钟）

1. 过去 90 天，你们改过 Agent 的模型、提示词、路由、工具或阈值吗？最近一次是什么、什么时候？
2. 改前和改后的文件 / 配置 / 提示词，现在还在吗？谁保管？
3. 当时怎么判断改好了？有没有同题对照或留出集？

**追问**：

- “如果只有日志、没有改前 / 改后产物，我们做不了证据包；你们能拿到原件吗？”
- “改的是哪一版：产物版、行为版、判据版，能说出三个来源吗？”

### 3.3 非作者复核人（3 分钟）

1. 如果做一次复核，谁会独立看？他和改的人是一个团队吗？
2. 他能拿出连续 60 分钟吗？还是只能“帮忙扫一眼”？
3. 他有没有权说“拒收 / 超时”，还是必须给通过？

### 3.4 数据条款（3 分钟）

1. 能否接受本地 / 客户环境只读旁挂，不接运行时、不改代码？
2. 留存 30 天、到期 5 天内删除并给回执，可以吗？
3. 有没有子处理方限制？密钥能否只走环境变量、绝不进包 / 进账？
4. 材料能否走客户批准通道，不经第三方 SaaS、不发公开链接？

### 3.5 下一步（2 分钟）

> 三项都成立：我发你一页决策卡和 M1–M7 材料清单，约 30–40 分钟，落到一个具体修改。  
> 任一项不成立：今天到此为止，我不做免费审计，也不追单。

### 3.6 复述确认（1 分钟）

> 我复述一下：最近一次改的是 ____，改前 / 改后现在 ____（能拿到 / 拿不到）；复核人是 ____（非作者 / 没有）；数据条款 ____（接受 / 待批 / 不接受）。对吗？

## 4. 判定与计数

| 状态 | 定义 | 计入什么 |
| --- | --- | --- |
| `qualified` | 三项全过 | 可转 30–40 分钟 G0 访谈；**不计入有效访谈 10 次** |
| `hold` | 有“说不清”，允许一次补充确认 | 不计入 |
| `not_qualified` | 任一项明确不过 | 计入通话分母，不计入有效访谈 |
| `declined` | 明确拒绝通话或拒绝三问 | 计入通话分母 |
| `no_response` | 两次联系后仍无回复 | 计入通话分母 |

**分母纪律**：

- 资格通话不是有效访谈；`qualified` 也不等于 G0 计数 +1；
- 有效访谈只在 30–40 分钟访谈后按 `访谈提纲-G0.md` §5/§7 判定；
- 不把“有兴趣”“可以聊聊”写成 `qualified`；
- AI 模拟通话、作者自演、同事代答：一律不计；
- 没发生就写 `NOT_RUN`，不写 0。

## 6. 停止规则

1. 没有真实修改 → 停，不约深访。
2. 拿不出改前 / 改后产物 → 停，不约深访。
3. 没有非作者复核人 / 复核人就是作者 → 停。
4. 拒绝数据条款任一硬项 → 停。
5. 要求“认证 / 防线 / 零风险 / 保证不出事” → 停。
6. 要求免费审计 / 先看完整方案再决定 → 停。
7. 只有采购角色，没有技术或风险角色 → 停。
8. 到 15 分钟未确认三项 → 按 `hold` 或 `not_qualified` 记录，不延长。
