# 非作者试读 · P0 出口判定表

- **用途**：作者 / 证据工程师在收到非作者试读记录后，按本表判定 P0 出口是否达成
- **版本**：v1.0（2026-10-20）
- **当前**：有效试读 **0 / 1**；尝试 **0**；判定 **0** 次；状态 `NOT_RUN`
- **边界**：本表是作者侧判定件，**不随试读包分发**，避免引导复核人；不是客户验收、不是合规意见

> 判定只回答一件事：这名非作者是否在独立、≤60 分钟、三态决定的条件下，说出了“这个包缺哪几段、为什么不能封包”。
> 它不回答“包好不好”“产品能不能卖”“方法可不可重复”。

## 1. 先判有效性（V1–V8，任一不过 → `INVALID`）

| # | 检查 | 通过条件 | 不过的典型 |
| --- | --- | --- | --- |
| V1 | 真人非作者 | 记录署名是真人，且不是作者、不是同一团队成员；有独立性声明 | AI / 代理 / 模拟 / 作者自填 |
| V2 | 独立完成 | 作者不在场、未口头补充、未解释材料；有干预即记，且不计 P0 出口 | “我来说明一下”后继续 |
| V3 | 60 分钟时间盒 | 有开始时间与每段用时；总用时 ≤60 分钟；>60 必须判 `超时 R6` 并写到达段 | 超时后仍给 `通过` / `拒收` |
| V4 | 三态决定 | 只选 `通过` / `拒收` / `超时` 之一；拒收带 R1–R7 码；超时带 R6 + 到达段 | “基本没问题”“待定” |
| V5 | 签名与时间 | 复核人署名 + 时间；证据工程师收件 + 时间 | 空白签名、无日期 |
| V6 | 记录原件与哈希 | 返回填写后的记录原件（或清晰扫描）；有文件 SHA-256；作者未代填 | 只有口头结论、无文件 |
| V7 | 决定后未改写 | 记录声明“决定后未改写”；修订另附页且保留原页；无作者事后编辑痕迹 | 作者替复核人润色结论 |
| V8 | 只用包内材料 | 复核人声明未看干跑、AI 演练、作者解释、外部材料 | 看了作者结论后复述 |

**计数规则**：V 不过 → 本次记 `INVALID`，计入“尝试”，不计入“有效试读”。不得把无效记录改写成有效，也不得把 AI 演练补成真人记录。

## 3. 真值表（结果由表决定，不由印象决定）

| 条件 | 结果 | 处置 |
| --- | --- | --- |
| 无返回记录 | `NOT_RUN` | 不计尝试；继续等外部动作 |
| 任一 V 不过 | `INVALID` | 计入尝试；修流程后换一名非作者重做 |
| V 全过，C1–C5 全过 | `PASS`（P0 出口达成） | 记 1 / 1；仍只证明“这一个人、这一次” |
| V 全过，任一 C 不过 | `FAIL` | 计入有效试读 0 / 1；修包 / 修说明后，换一名非作者重试 |

> 注意：P0 的 `PASS` 通常对应复核人判 `拒收`；它表示“这次试读达标”，不表示“包通过”。

**停止规则**：
1. 同一处歧义连续 3 次有效 `FAIL` → 先改包与说明，不换人硬试；
2. 两名有效复核人结论冲突 → 两份都保留，不取平均、不改写；
3. 任何一次把 AI / 作者 / 代理记成真人 → 本次判定作废，重新计数；
4. `PASS` 只关闭 P0 出口，不关闭 G1、P1 或任何外部闸门。

## 6. 本表不证明什么

1. 不证明包可封、可交付、可规模化；
2. 不证明方法可重复：`PASS` 只来自 1 名非作者、1 个内部样本、1 次试读；
3. 不替代 P1 的“真实客户包 + 非作者 60 分钟复核”：P0 用的是内部样本，没有客户、没有原像、没有真实修改；
4. 不把 AI 演练、作者自测、桌面推演计入任何通过率；
5. 不覆盖安全 / 合规 / 模型正确性；审计层只对应 MCP08，不是防线。
