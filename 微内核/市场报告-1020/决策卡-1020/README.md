## 已知限制

- **PDF 文本层**：中文大面积不可提取，01 区按行交错；视觉阅读不受影响。需要复制 / 检索时用 HTML 源文件。第二轮由 minor 升级为 2-major，未修。
- **术语密度**：`R/N 双臂`、`版本三元组`、`产物原像` 对非技术合规读者仍需一句解释；真人测试若确认，应加脚注而不是扩写正文。
- **单页约束**：当前无纵向余量（1096/1096），任何新增正文都必须先删等量内容。
- **反臂**：只用于证明尺子会红，不是可比稿，不对外。
- **试点函**：草案 v0.1，需双方法务 / 安全书面确认；不是合同。
- **边界**：本页是研究与试点邀请，不是报价单、投资建议或合规意见；agentkernel 不拦截、不调度、不联网、不执行工具；审计层不是防线。

## 这一页要读者决定什么

1. 是否提供一次真实修改样本（含修改前后产物、一次失败复盘）。
2. 是否指派 1 名非作者，在 60 分钟内按清单独立复核。
3. 是否接受 6 周、3–5 千美元的试点边界；做不出可复核证据包，不收尾款。
