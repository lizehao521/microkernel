# 决策卡可用性测试方案

- **对象**：`decision-card.html` / `decision-card.pdf`（A4 单页，V2.1 对外决策卡）
- **方法**：远程主持式，5 秒第一印象 + 理解测试 + 信任/克制度评分 + POC 意向
- **目标样本**：8 人（AI 平台 3 / 安全工程 3 / 合规风险 2）+ 1 场试测
- **单场时长**：30 分钟
- **AI 模拟读者**：第二轮 DONE（3 位，非真人；29/30），不计入通过率
- **真人状态**：**NOT_RUN**（截至 2026-10-20 未执行；本文是可直接执行的方案，不是结果）
- **不可替代性**：AI 模拟读者只能发现问题，不能产生通过率；本方案的所有阈值只对真人样本生效

> **协议校准（2026-10-20，两轮）**：第一轮 3 位 AI 模拟读者（非真人）指出“决策项不在首屏”，当时把决策项移到 T4 / Q8。V2.1 已把三件事移到首屏 00 决策带；第二轮 3 位 AI 模拟读者均能在首屏说出三件事。因此从 V2.1 起，T1 恢复“能说出至少 2/3 件”作为成功标准。该调整仍来自 AI 模拟，不是真人数据。

## 1. 测试要回答什么

| # | 研究问题 | 对应的卡上设计 |
| --- | --- | --- |
| RQ1 | 5 秒内，读者能否说出“卖的是一次修改的可复核证据包”，而不是“又一个日志/可观测性平台”？ | 标题、lead、`我们押` |
| RQ2 | 读者能否区分 A 级（链自洽）与 X 级（原像/版本/拒收计数/NOT_RUN）？ | 状态条、三张证据卡 |
| RQ3 | 读者会不会把“审计层不是防线 / 不构成合规认证”误读成“有防线 / 已合规”？ | 03 能说 / 不能说、页脚 |
| RQ4 | 读者是否愿意提供一次真实修改样本、指派非作者复核，或安排 30 分钟深聊？ | 00 决策带、04 试点 |

研究问题只问“能不能完成 / 在哪里误读”，不问“喜不喜欢 / 好不好看”。

## 2. 样本与招募

### 2.1 分段

| 分段 | 人数 | 必要条件 | 排除 |
| --- | --- | --- | --- |
| AI 平台负责人 | 3 | 负责 Agent runtime / 模型平台 / 评测基础设施，近 12 个月做过一次行为变更或回归 | 作者本人、直接合作方、Agentkernel 贡献者 |
| 安全工程负责人 | 3 | 做过 Agent / LLM 应用的安全评审或事故复盘 | 只做传统网络安全、无 LLM 系统经验 |
| 合规 / 风险负责人 | 2 | 熟悉 EU AI Act、模型治理或供应商审计 | 法务销售、纯咨询顾问 |

- **加分**：过去 6 个月遇到过“改坏了无法归因”或“审计要拿那次修改”。
- **样本不足时**：少于 5 人只报“早期信号”，不下“X% 读者”的结论。
- **不在本机凑数**：没有真实目标读者时，状态保持 NOT_RUN，不用同事/作者/AI 冒充。

### 2.2 时间表（可执行版）

| 阶段 | 工作量 | 说明 |
| --- | --- | --- |
| 招募 | 5–7 天 | 由你方现有渠道邀约；不通过付费panel |
| 试测 pilot | 1 场 | 必做；只用于修剧本，不计入 8 人 |
| 正式 | 8 场 × 30 分钟 | 每天最多 3 场，场间留 30 分钟 |
| 整理 | 每场 30 分钟 | 当天完成记录，避免记忆污染 |

## 3. 任务剧本

### T1 · 5 秒第一印象（must）

- **场景**：你收到一页对外决策卡，只有 5 秒扫一眼。
- **操作**：展示首屏 5 秒 → 切走 → 提问。
- **成功标准**（可观察）：
  1. 能说出“给 Agent 的修改做可复核证据 / 证据包”，不是“日志平台 / 监控 / 托管服务”；
  2. 能说出至少一个“已证明”和一个“没证明”；
  3. 能说出首屏三件事中至少 2 件（提供样本 / 指派非作者复核 / 接受 6 周 3–5 千美元边界）。
- **观察点**：第一眼看哪里；是否读到 `NOT_RUN`；是否把 `A 级` 当成“整体可信”（V2.1 首屏 A 级仍无内联边界，若发生即记 F9）；是否在首屏寻找“要我做什么”。
- **预计**：5 分钟。

### T2 · 理解测试（must）

- **场景**：现在可以完整阅读，请逐题回答，不要猜。
- **题与答案键**：

| # | 问题 | 正确答案（评分点） |
| --- | --- | --- |
| Q1 | 这张卡在卖什么？ | 一次 Agent 修改的可复核证据包 / 6 周付费试点；不是日志平台、不是托管服务 |
| Q2 | `链自洽 2,940 / 2,940` 证明什么、不证明什么？ | 证明记录完整、顺序自洽、未被改动；不证明内容为真、行为正确、攻击被挡 |
| Q3 | 产物原像与版本三元组现在有吗？ | 没有；当前缺口（产物内容 0 / 2,940、无版本字段），链外证据包补 |
| Q4 | R/N 双臂分别是什么？跑了吗？ | R 臂 = 留出集（账本 + 原像 + 版本 + 清单）；N 臂 = 无记录（只有 trace / 日志）；均未运行，`NOT_RUN` |
| Q5 | 提示注入发生时，agentkernel 能挡住吗？ | 不能；审计层不是防线，不拦截、不调度、不联网、不执行工具 |
| Q6 | 卡是否声称“符合 EU AI Act”或“已通过合规认证”？ | 没有；只说为第 12 条记录义务提供技术证据，不构成合规认证 |
| Q7 | 试点周期、价格、何时不收尾款？由谁判定“做不出”？ | 6 周；3–5 千美元；做不出可复核证据包不收尾款；由客户指定的非作者复核人按 A1–A5 判定，作者不参与 |
| Q8 | 要读者决定哪三件事？其中 60 分钟复核的通过 / 拒收判据是什么？超时怎么算？ | 提供真实修改样本；指派 1 名非作者独立复核；接受 6 周 3–5 千美元边界。通过 = 非作者按清单复算链并定位断点；否则拒收；超时按拒收并记原因；细则见试点函 |

- **成功标准**：
  - 每位读者 ≥6/8 正确；8 人平均 ≥7/8；
  - **零人**把 Q5 答成“能挡住”，**零人**把 Q6 答成“已认证/符合”。
- **观察点**：Q2 与 Q3 是否混淆“账没被改”和“内容为真”；Q4 是否把 `NOT_RUN` 读成“失败”或“0”。

### T3 · 信任与克制度（must）

- **操作**：完整阅读后打分，并指出一句“最像营销”的话。
- **量表**：
  - 信任度 1–5（1=完全不信，5=可信）；
  - 克制度 1–5（1=明显夸大，5=非常克制、不夸大）；
  - 是否愿意把这页转给内部安全/法务：是 / 否 / 有条件。
- **成功标准**：
  - 信任均值 ≥4.0；
  - 克制度均值 ≥4.0，且**零人**打 1–2；
  - 被指为“营销”的句子，不得是 A 级读数或 `NOT_RUN` 标注本身。
- **观察点**：诚实披露 X 项是增加信任还是降低信任；读者是否要求“给个大概通过率”。

### T4 · POC 意向（should）

- **操作**：读完 00 / 04 后回答。
- **问题**：
  1. 你是否愿意提供一次真实修改样本？愿意 / 需要内部审批 / 不愿意；
  2. 你是否愿意指派 1 名非作者做 60 分钟复核？愿意 / 不确定 / 不愿意；
  3. 0–5 分，你推动内部评估的意愿；
  4. 如果要拒绝，缺的是什么？
- **成功标准**：≥2 人 POC 意向 ≥4；≥1 人愿意安排 30 分钟深聊。
- **观察点**：拒绝理由集中在“证据不足”还是“预算/优先级”；是否要求先看别人的案例。

### T5 · 反臂对照（可选，仅用于校准读者，不对外）

- **设计**：把读者随机分为两组，一组看主卡，一组看 `anti-arm.html`（故意夸大版）；同一套 Q1–Q8 与评分。
- **目的**：验证读者能否抓出“闭环已通 / 内容可信 / 已认证 / +38%”等越界话术。
- **判据**：看反臂的读者，克制度应显著低于主卡组；若两组无差异，说明读者没有在读限定语，主卡的“诚实”没有起作用。
- **红线**：反臂只用于测试校准，不对外发送，不作为可比稿。

## 4. 主持脚本

### 4.1 暖场（3 分钟）

- “今天测的是这张卡，不是你。你看不懂、觉得可疑，都是卡的问题。”
- “我不会解释卡上的内容；你问‘这是什么意思’，我会反问你‘你读到的是什么’。”
- 征得录屏/录音同意；说明只用于内部改进，不公开个人身份。

### 4.2 5 秒协议（T1）

```
我给你看一页东西，只有 5 秒。看完我会切走，然后问你三个问题。
不用记细节，凭第一印象答。
（展示 5 秒，切走）
1. 它在卖什么？
2. 它证明了什么？没证明什么？
3. 它要你做什么决定？
```

### 4.3 理解测试（T2）

- 完整展示卡片，允许滚动/放大。
- 逐题问，不提示答案；答错不纠正，继续下一题。
- 记录原话，不替读者总结。

### 4.4 中立追问（禁止引导）

- “你刚才在看哪一行？”
- “你读到这句话时，理解成什么？”
- “`NOT_RUN` 在你看来是什么意思？”
- “如果这句话删掉，你会不会更信 / 更不信？”
- “你为什么会觉得它是 / 不是认证？”

**禁止**：
- “这里是不是很清楚？”（引导）
- “其实它的意思是……”（解释设计）
- “很多人都没看懂这里。”（暗示）
- 读者卡住立刻给答案（至少等 30 秒）

### 4.5 收尾（5 分钟）

- “整页最让你犹豫的是哪一句？”
- “如果只能改一处，你改哪里？”
- “你会把这页转给谁？为什么？”
- “还有什么我没问、但你觉得重要的？”

### 4.6 反偏见清单

1. 不救场：读者卡住先等 30 秒，只问“你现在在想什么”。
2. 不解释设计：读者问“这是什么”，反问“你觉得它想说什么”。
3. 不附和：读者骂“这就是营销”，只记录，不点头也不辩护。
4. 不纠正路径：读者漏读某段，不指给他，记录“未读到”。
5. 不替读者总结：debrief 时不写“所以你觉得 X 不好”。
6. 不把 AI 模拟当真人：模拟结果单独标注，不混入通过率。

## 6. 判定与严重度

### 6.1 任务级指标

| 指标 | 公式 | 红线 |
| --- | --- | --- |
| T1 成功率 | 三项成功标准全满足 / 有效样本 | <70% 必出 critical |
| T2 平均正确 | 8 题正确数之和 / 样本 | <7/8 必出 major |
| 误读率（防线/认证） | 答成“能挡住/已认证”的人数 / 样本 | >0 即 critical |
| 信任均值 | 1–5 均值 | <4.0 出 major |
| 克制度均值 | 1–5 均值 | <4.0 出 major |
| POC 意向 ≥4 | 人数 / 样本 | <25% 出 major |

### 6.2 Nielsen 0–4 严重度

| 等级 | 定义 | 处置 |
| --- | --- | --- |
| 4 catastrophic | 读者把 X 项当成已证明，或据此做出采购/合规判断 | 上线前必须修 |
| 3 critical | 读者误读“防线/认证”，或 5 秒内完全说不出卖什么 | 上线前必须修 |
| 2 major | 反复漏读 NOT_RUN / 把 A 级当整体可信，但经提示能纠正 | 首版修 |
| 1 minor | 个别措辞犹豫，不影响理解 | 批量修 |
| 0 cosmetic | 纯视觉细节 | 视情况 |

**频次不替代严重度**：1 人把“不构成合规认证”读成“已认证”，也是 catastrophic。

### 6.3 Findings 证据链

每条 finding 必须含：

```
id / task_id / severity / frequency / affected_participants /
verbatim_quotes / stuck_points / suggested_fix_direction /
recommended_next_skill
```

没有原话与任务编号的，不进 findings，只进“观察笔记”。

## 8. 边界

- 本方案不是合规认证，不替代法务/安全评审。
- 8 人样本只能发现主要可用性问题，不能给出统计显著性。
- 读者说“愿意”不等于真实采购；POC 意向只是意向。
- 反臂只用于证明尺子会红，不对外。
- 任何“通过率”只能来自真人记录；AI 模拟读者的答案只作线索。
- 第二轮 AI 模拟读者的“首屏”是同一提示内的分段阅读，模型能看到全文；不能当严格 5 秒测试。
- PDF 文本层中文不可提取，需要复制 / 检索时用 HTML；这是打印管线问题，不是理解测试问题。
