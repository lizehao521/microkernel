## 4. Findings（AI 模拟，非真人）

频次分母均为 3 位有效模拟读者；严重度按 Nielsen 0–4。

### F1 · “可写进合同”清单混入未验证能力

- **频次**：3/3
- **严重度**：**3-critical**
- **证据**：
  - 合规：“‘可以写进合同与材料：一次修改可被另一个人复核、回滚、披露’——但‘像’‘验’两项均为 X 未跑，合同级承诺没有实测支撑。”
  - 红队：“原像、版本、真人复核全是 X，却先写进合同语域，构成事实承诺。”
  - AI 平台：“叠加成本没答……等于我得再养一套旁挂数据。”
- **处置**：**已修**。标题改为“可以对外说（带限定）”；该条加 `*`；章节说明改为“* 试点验证项，未验证前不写成合同承诺”。
- **未复测**：修订后没有再跑模拟读者。

### F2 · “独立复算”中的“独立”是谁

- **频次**：3/3
- **严重度**：2-major
- **证据**：
  - AI 平台：“A 工具自印 + 独立复算中的‘独立’是谁？若是作者自复算，A 级站不住。”
  - 合规：“‘独立复算’是谁做的？我方无法复现。”
- **处置**：**已修**。图例改为“A 工具自印 + 可复算”，不再暗示有外部独立方。

### F3 · 60 分钟复核没有验收判据

- **频次**：2/3 明确追问（AI 平台、红队）；合规也要求可复现脚本与哈希
- **严重度**：2-major
- **证据**：
  - AI 平台：“‘60 分钟内复核’是硬指标还是目标？同时写着‘未验证：真人计时’，失败条件不明确。”
  - 红队：“‘可复核’没有验收判据与计时口径，退款条件不可执行。”
- **处置**：**部分修**。“验”卡脚注改为“验收口径：清单与拒收判据随试点函给出”。清单内容仍未落到卡上（单页无余量），属于试点函待补。

### F4 · 样本数据处理条款缺失

- **频次**：1/3（合规）
- **严重度**：2-major
- **证据**：“样本含‘修改前后的产物’‘一次失败复盘’，可能带生产数据或个人信息；卡上无驻留地、留存期、删除、子处理方、责任上限。”
- **处置**：**未修**。单页无余量；列入试点函必填条款。卡片只保留“只在你指定的范围内处理样本”。

### F5 · 叠加成本与 trace ID 对齐没有回答

- **频次**：1/3（AI 平台）
- **严重度**：2-major
- **证据**：“既说‘不必重买 trace / eval’，又说‘当前账本无此字段，放链外证据包补’，等于我得再养一套旁挂数据；谁维护、怎么和现有 trace ID 对齐，卡上空白。”
- **处置**：**未修**。这是产品问题，不能靠改文案解决；先记录，等真实样本验证后再决定是否写进卡。

### F6 · POC 意向低

- **频次**：3/3（2 / 2 / 3 分）
- **严重度**：信号，不按缺陷计
- **证据**：
  - 合规：“成本低可听，但对合规证据链用途有限。”
  - AI 平台：“能否先给我那份‘非作者 60 分钟复核清单’？我要看拒收判据是否写死。”
- **解读**：卡片完成了“讲清楚 + 不夸大”，但没有完成“给出下一步的确定感”。在真实样本、第三方复核记录、验收清单出现之前，低意向是合理反应，不应靠加形容词解决。
- **处置**：**不改卡**。下一轮真人测试重点验证：低意向是“证据不足”还是“没有这个预算科目”。

### F7 · 决策项不在首屏

- **频次**：3/3
- **严重度**：1-minor
- **证据**：三人均在第一步说“A 区看不出要我做什么决定”。
- **处置**：**改测试协议，不改版式**。T1 只测卖点与 A/X 边界；决策项移到 T4/Q8。保留“缩略图只看上半页”的观察。

### F8 · PDF 文本层两栏交错

- **频次**：机械检查命中 1 处（01/05）
- **严重度**：1-minor
- **证据**：`pdftotext -layout` 在 01 区出现“像能、回答行为‘发版生本、了判据么’版本”这类交错；视觉版面正常。
- **处置**：**未修**。需要复制时用 HTML；若后续要发可复制的 PDF，再改单栏版式。
